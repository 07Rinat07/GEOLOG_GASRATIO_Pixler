GEOLOG GASRATIO@Pixler — проект обновлён до версии 0.7.83
=========================================================

Это уже готовая обновлённая папка проекта. Ничего вручную копировать по отдельным
каталогам не нужно.

Что сделать на своём компьютере:

1. Закройте программу и редактор кода, если проект открыт.
2. Переименуйте старую папку проекта, например:
      GEOLOG_GASRATIO_Pixler_OLD_0.7.82
3. Распакуйте архив с этой папкой рядом со старой.
4. Откройте новую папку GEOLOG_GASRATIO_Pixler_UPDATED_0.7.83 в PyCharm или VS Code.
5. В терминале проекта выполните:

      python -m venv .venv
      .venv\Scripts\activate
      python -m pip install --upgrade pip
      python -m pip install -e .

6. Запуск программы:

      python -m geoworkbench.app.main
