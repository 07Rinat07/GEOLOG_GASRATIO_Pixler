# Formula profiles

Сюда добавляются только подтверждённые профили формул Pixler, Wetness, Balance,
Character, коэффициента флюидности и D-экспоненты.

Каждый профиль должен содержать:

- ID и версию;
- точную формулу;
- перечень входов и единиц;
- источник/методику;
- контрольный численный пример;
- тесты граничных случаев.

Профиль регистрируется через `FormulaProfileRegistry`, который выполняет контрольный пример
до добавления профиля и строит dependency graph из `required_inputs` и `output_mnemonic`.

Формулы не должны добавляться по памяти или без проверяемого источника.

## Встроенные подтверждённые профили

`build_sourced_formula_registry()` регистрирует семь профилей:

- Haworth `Wh`, `Bh`, `Ch` для компонентов C1-C5;
- Pixler `C1/C2`, `C1/C3`, `C1/(iC4+nC4)`, `C1/(iC5+nC5)`.

Отдельный режим отчёта ОПУС, не стандартный gas-ratio workflow, создаёт четыре кривые профиля
`opus-lukyanov-c1-c5-relative-1987-1997`: `OPUS3`, `OPUS4`, `OPUS_K1_3` и
`OPUS_1_5`. Рабочие C1-C5 хранятся в `% об.`, относительные — как `OPUS_P1-P5`. Входные ppm
переводятся по правилу `1 % об. = 10 000 ppm`; исходные кривые сохраняются. Показатели
нормируются по сумме C1-C5 и являются скрининговыми признаками,
а не взаимоисключающей классификацией. Предварительная подпись флюида формируется
только при единственном пересечении опубликованных перекрывающихся диапазонов всех
доступных показателей. Для классификации используются только строки, превысившие
порог аномалии; при пустом или неоднозначном пересечении автоматически применяется
явно помеченный резерв Haworth/Pixler. `OPUS3/OPUS4` независимо сверены по открыто
опубликованным формулам; `OPUS_K1_3/OPUS_1_5` и диапазоны имеют проверяемую вторичную
сверку с библиографией к работам 1987/1997. Эта разница указывается в отчёте.
Неподтверждённый `OPUS5_REF` и строгое голосование из Integration Kit в текущий исторический
runtime не включены. Для отдельного будущего профиля `OPUS Gasomer` принят другой прикладной
контракт из книги пользователя: нормализация на независимый TotalGas, пять показателей,
уникальная мода с явной ничьей и построчная агрегация внутри интервала. Пятый показатель и
границы помечены как workbook-derived, а не как подтверждённая первичная формула. Этап
воспроизводимости книги и `OPUS-02/03` реализованы в versioned JSON-профиле, scalar/golden
fixture и vectorized-ядре с ppm/`% об.`, LOD/QC states, data-driven bands и интервальной
support-агрегацией синхронных строк. Legacy MAX изолирован compatibility marker, explicit
maximum span и source depths. Локальный detector по `ΔTG`, robust z и LOD-floor contrast также
готов; его versioned параметры требуют полевой калибровки. Runtime controller и отчёт ещё не
подключены.
Инструкция реализации: [`docs/OPUS_GASOMER_IMPLEMENTATION.md`](../../docs/OPUS_GASOMER_IMPLEMENTATION.md).

`build_all_sourced_formula_registry()` дополнительно регистрирует профили
Jorden–Shirley `DEXP` и Rehm–McClendon `DEXPC`. Описание единиц и ограничений:
[`docs/DEXP_FORMULAS.md`](../../docs/DEXP_FORMULAS.md).

Полные библиографические записи, ссылки и ограничения применения находятся в
[`docs/MUD_GAS_FORMULAS.md`](../../docs/MUD_GAS_FORMULAS.md). Значения всех
газовых компонентов в одной формуле должны быть выражены в одинаковых единицах.
