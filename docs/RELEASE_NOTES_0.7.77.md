# GEOLOG GASRATIO@Pixler 0.7.77 — WITS0 live monitor

## Назначение среза

Версия 0.7.77 завершает основной объём этапа E WITS0-интеграции. Поверх growing
`AcquisitionDataset` и append-only `AcquisitionSession` добавлена read-only проекция
`AcquisitionLiveView` и вкладка **Монитор** в окне захвата WITS Level 0.

## Текущие значения

Таблица текущих значений показывает выбранные каналы, последнее конечное значение, единицу и
состояние качества. Если в последней строке канал отсутствует, последнее корректное значение
сохраняется для оператора, но явно помечается как «нет нового значения». Поддерживаются состояния
`good`, `missing`, `invalid`, `source_gap` и `stale`.

## Графики по времени и глубине

- активный time/depth index используется напрямую;
- для time-index Dataset глубинная ось может быть построена read-only из подтверждённой кривой
  `HOLE_DEPTH`, `BIT_DEPTH`, `MD`, `GAS_DEPTH` или другого семантически распознанного depth-канала;
- для depth-index Dataset временная ось строится из UTC `AcquisitionRecord.received_at`;
- производный индекс не изменяет Dataset и не записывается в проект;
- пользователь выбирает отображаемые каналы без остановки acquisition.

## Live, pause-view и история

`auto-follow` удерживает правую границу окна на последней точке. **Пауза просмотра** фиксирует
видимое число строк, но `Wits0AcquisitionRuntime` продолжает принимать, нормализовать и записывать
данные. После возобновления монитор переходит к актуальному хвосту. При отключённом auto-follow
масштабирование и прокрутка задают историческое окно.

## Downsampling и маркеры качества

Для каждой видимой кривой используется общий peak-preserving `select_visible_samples()`, который
сохраняет NaN-разрывы и ограничивает число отрисовываемых точек. На графике показываются:

- разрывы source sequence;
- аномально большие интервалы оси;
- invalid source values;
- диапазоны отсутствующих значений.

В `AcquisitionRecord.source` дополнительно сохраняются `sequence-status`, raw SHA-256 и
структурированные quality-коды по WITS `record/item`.

## Совместимость и проверка

Project format остаётся **v20**, form schema — **v8**, tablet layout — **v18**. Миграция
существующих проектов не требуется. Компактные колонки 50%, готовые ширины 48/80, все готовые и
пользовательские формы, сохранение через Ctrl+S и повторное открытие остаются без изменений.

Qt runtime-проверка требует Windows-окружение с PySide6/pyqtgraph и реальный anonymized GSWITS raw
stream. Пауза относится только к представлению и не заменяет controlled close acquisition-сессии.
