# GEOLOG GASRATIO@Pixler 0.7.83 — GeoScape WITS үйлесімділігі

GSWITS стандартты тақырыбы түзетілді: `01` — ұңғыма, `02` — бүйір оқпан/секция,
`03` — жазба идентификаторы, `04` — sequence, `05` — күн, `06` — уақыт, `07` — жұмыс коды.
Sequence бақылауы, gap, duplicate және provenance енді item `04` мәнін қолданады.

GeoSensor WITS Level 0 толық туынды каталогы қосылды: 963 өріс, 1–25 жазбалар, типтер және mnemonic.
Каталог `GeoScape/WITS.csv` файлынан қайталанатын құралмен жасалады; vendor EXE/BPL/MDB/PDF wheel
және бастапқы архивке кірмейді. Project format `v20`, form schema `v8`, tablet layout `v18`, дайын
пайдаланушы үлгісі және 50%, 48, 80 ықшам шектері өзгеріссіз қалды.
