# GEOLOG GASRATIO@Pixler 0.7.66 — бірыңғай каталог, диагностика тазарту және бейімделетін панельдер

## Өзгерістер

- **Пішіндер кітапханасы**, **Пішін жасау** және **Пайдаланушы пішінін сақтау** енді бір
  авторитетті каталогты қолданады: дайын, барлық **18 зауыттық** және пайдаланушы пішіндері барлық
  терезеде бірдей көрсетіледі.
- Толық зауыттық жиын тек сақтау кезінде көрініп, қалыпты кітапханада қысқартылған тізім болған
  сәйкессіздік жойылды.
- Негізгі жоғарғы панель және **«Пішінді өңдеу (F4)»** панелі бейімделетін режим алды. Ен жетпегенде
  екінші дәрежелі командалар тек белгішеге ауысады, сондықтан оң жақтағы өңдеу ауыстырғышы терезе
  ішінде қалады.
- **Анықтама** мәзіріне **«Диагностика деректерін тазарту…»** командасы қосылды. Ол растаудан кейін
  жиналған журналдар мен импорт есептерін жояды және журнал жүргізу автоматты түрде жалғасады.
- Импорт есептерінің автоматты сақталуы әр түр үшін соңғы 30 файлмен шектелді.

## Тазарту қауіпсіздігі

Тазарту жобаларға, LAS файлдарына, пайдаланушы пішіндеріне, баптауларға және пайдаланушы экспорттаған
диагностика ZIP-пакеттеріне әсер етпейді.

## Үйлесімділік

Project format **v20**, form schema **v8**, tablet layout **v18** болып қалады.
