# GEOLOG GASRATIO@Pixler 0.7.89

Жаңа GeoScape2 GS2 деректер жиынын ашқаннан кейін пішінді қолдану және кері
қалпына келтіру қатесі түзетілді. Пішінде сақталған тік ось идентификаторы енді
ағымдағы dataset құрамында тексеріледі. Ескірген сілтеме `NoneType.role` қатесін
шығармай, белсенді осьпен ауыстырылады. Абсолют уақыт үшін салыстырмалы TIME осі
DATETIME осіне ауысады, ал қолмен таңдалған тереңдік осі сақталады.

Жоба пішімі v21, пішін схемасы v9 және планшет layout нұсқасы v19 болып қалады.
Зауыттық және пайдаланушы пішіндері көшірусіз үйлесімді.
