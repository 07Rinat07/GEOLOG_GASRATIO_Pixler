# WITS Level 0 қабылдау

## Мақсаты

**Файл → WITS Level 0 қабылдау...** командасы GSWITS TCP ағынын қабылдап, бастапқы байттарды
өзгеріссіз сақтайды. Бұл кезең қауіпсіз raw-қабылдау шекарасы болып табылады: мәндер әзірше
Dataset-ке жазылмайды және дабылдар орындалмайды.

## TCP серверін баптау

Бұл режимді GSWITS **Шығыс қосылым (TCP клиенті)** ретінде бапталған кезде қолданыңыз.

1. **Кіріс қосылым — TCP сервері** режимін таңдаңыз.
2. Барлық жергілікті интерфейстер үшін `0.0.0.0`, ал бір интерфейс үшін оның IP мекенжайын енгізіңіз.
3. GSWITS қосылатын дәл сол портты көрсетіңіз.
4. Raw-деректер қалтасын таңдап, **Қабылдауды бастау** батырмасын басыңыз.
5. GSWITS желі баптауларын сақтап, қосылым индикаторын тексеріңіз.

## TCP клиентін баптау

Бұл режимді GSWITS **Кіріс қосылым (TCP сервері)** ретінде бапталған кезде қолданыңыз.

1. **Шығыс қосылым — TCP клиенті** режимін таңдаңыз.
2. GSWITS компьютерінің IP мекенжайы мен портын енгізіңіз.
3. **Қабылдауды бастау** батырмасын басыңыз.
4. Қосылым үзілгеннен кейін Pixler шектелген өсетін кідіріспен автоматты түрде қайта қосылады.

## Сақталатын деректер

Әр қосылымға жеке қалта жасалады. `*.wits` binary-файлдары нақты келген байттарды, ал
`*.chunks.jsonl` файлдары әр TCP chunk үшін UTC уақытын, offset және өлшемді сақтайды. Сегменттер
қайта жазылмайды және deterministic replay үшін жарамды.

## Тексеру

**Соңғы пакеттер** қойындысы `&&` және `!!` маркерлерімен шектелген frames көрсетеді.
**Қосылымдар мен қателер** қосылу, ажырау, raw-сегмент ашылуы және қателерді көрсетеді. Терезені
жабу worker-ді тоқтатып, файлдарды жабады.

## Шектеулер

- GeoScape кіріктірілген профилі GSWITS нұсқаулығына негізделген және нақты raw арқылы расталуы тиіс;
- unknown fields бұл кезеңде түсіндірілмейді;
- WITS0 портын Интернетке тікелей ашуға болмайды;
- raw-файлдар жобаны **Ctrl+S** арқылы сақтауды алмастырмайды және reopen кейін жеке файл болып қалады.
