# WITS0 live monitor

## Мақсаты

**Монитор** қойындысы growing WITS0 Dataset үшін read-only проекция көрсетеді. Ол
`AcquisitionSession` өзгертпейді, TCP қабылдауын тоқтатпайды және `AcquisitionController`
шекарасын айналып өтпейді.

## Ағымдағы мәндер

Пайдаланушы сол жақтан арналарды таңдайды. Әр жол соңғы жарамды мәнді, бірлікті және сапаны
көрсетеді. Соңғы жолда арна мәні болмаса, алдыңғы жарамды мән `missing` күйімен көрінеді.
`stale` күйі UTC қабылдау уақыты бойынша есептеледі.

## Уақыт және тереңдік осьтері

**Автоматты** режим Dataset белсенді индексін қолданады. **Уақыт** және **Тереңдік** нақты индекс
бар болса соны қолданады. Екінші ось болмаса, live monitor тек read-only ось жасайды:

- UTC уақытын `AcquisitionRecord.received_at` арқылы;
- тереңдікті расталған semantic depth curve арқылы.

Туынды ось Dataset құрамына қосылмайды және жобаға сақталмайды.

## Auto-follow, pause-view және тарих

Auto-follow соңғы нүктемен аяқталатын берілген терезені көрсетеді. Оны өшіру тарихты жылжыту мен
масштабтауды қосады. **Көрсетуді кідірту** көрінетін жолдар санын бекітеді, бірақ acquisition
деректерді қабылдап, жазуды жалғастырады. Жалғастыру ағымдағы соңына өтеді.

## Downsampling

`select_visible_samples()` таңдалған терезедегі нүктелер санын шектеп, peaks және NaN үзілістерін
сақтайды. Бастапқы Dataset пен append-only records өзгермейді. Төменгі жол бастапқы және
көрсетілген нүктелер санын береді.

## Сапа және үзіліс маркерлері

График source-sequence gaps, осьтің үлкен аралықтарын, invalid values және missing spans көрсетеді.
Marker provenance append-only records ішінен алынады. Маркерлер диагностикаға көмектеседі және ГТИ
маманының шешімін алмастырмайды.

## Оператор пішіндері және толық экран

Пішінді **қосылымға дейін** таңдауға болады. Зауыттық пішіндер бастапқы үлгі болып қалады, бірақ
әр жұмыс пішінін өзгертуге болады: арналар мен графиктерді қосу/алып тастау, осьті, тарих
терезесін және нүкте шегін өзгерту. **Пішінді сақтау** параметрлерді сессияның curve ID бойынша
емес, canonical mnemonic бойынша сақтайды; **Қалпына келтіру** factory template-ке қайтарады.

Монитор бейімделеді: параметрлер панелін жасыруға болады, live view толық экранға шығарылып,
қабылдауды тоқтатпай және runtime-ды қайта құрмай кері қайтарылады. LIVE PREVIEW-ден тұрақты
runtime-ға өткенде таңдалған пішін сақталуы тиіс.

## Live есептік қисықтар және инженерлік оқиғалар

WITS-CALC-01 WH/BH/CH, Pixler C1/C2–C1/C5 және DEXP/DEXPC мәндерін virtual read-only арналар
ретінде қосады. Batch есептеулеріндегі сол versioned formula registry қолданылады; Qt/UI ішінде
формулалардың екінші көшірмесі болмайды. DEXP тек ROP/RPM/WOB/BIT және бірлік түрлендірулері
дұрыс болғанда есептеледі; DEXPC үшін нақты және қалыпты ерітінді тығыздығы да қажет.

Интерфейс үш ұғымды бөлек көрсетеді:

- Haworth/Pixler бойынша **fluid screening**;
- **gas origin/context**: background, formation show, connection gas, trip gas, circulated gas
  немесе elevated-unclassified;
- параметр min/max шегінен шыққан **threshold alarm**.

Түсті сызық/жолақ нақты тереңдікке немесе уақытқа бекітіледі. Мәтін график жиегінде көлденең
шағын badge ретінде көрсетіледі; жақын badges тек көрнекі түрде ығыстырылады, оқиға координатасы
өзгермейді.

## Min/max дабылдары

WITS-ALARM-01 әр арнаға optional min/max, visual/audio enable, hysteresis, debounce/minimum-duration,
acknowledgement және global mute береді. Alarm — параметрді бақылау құралы, геологиялық қорытынды
емес. Дыбыс әр sample сайын емес, күй ауысқанда ғана беріледі.

## Шектеулер және қабылдау

Оператор dashboard үйлесімді арналарды технологиялық панельдерге біріктіреді, ал бірліктері
үйлеспейтін арналарды тәуелсіз X-autoscale бар көршілес тректерге автоматты түрде бөледі.
Арна таңдауы, ось, auto-follow, pause-view және history-window параметрлері workspace ішінде
сақталады.

Transient LIVE PREVIEW ең соңғы 2000 кадрды ғана сақтайды. Оның туынды Dataset, curve arrays,
preview-session records және record-id index құрылымдары да bounded: жоғарғы шекке жеткенде
preview runtime сақталған кадрлар терезесінен қайта құрылады және curve ID тұрақты қалады.
Тұрақты reviewed acquisition бұл механизммен қысқартылмайды.

Егер ескі preview кадры жадтан шығарылған болса, persistent backfill енді fail-closed режимінде:
сессияны бастау әрекеті шығарылған/retained кадрлар санын және сақталған уақыт аралығын көрсетеді,
ал AcquisitionSession жасалмайды. Сондықтан жадтағы қысқартылған соңғы бөлік толық тарих ретінде
үнсіз қабылданбайды. Қолжетімді raw аралығын replay жасау және кейінгі айқын шекараны таңдау
WITS-MEM-01 келесі бөлігі болып қалады. Windows Qt smoke test және нақты anonymized GSWITS raw
ағынымен тексеру міндетті.
