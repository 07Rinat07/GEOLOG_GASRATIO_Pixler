# GEOLOG GASRATIO@Pixler 0.7.93

## Тілді ауыстырған кезде пішін атауларын аудару

- Орыс, қазақ немесе ағылшын тілін ауыстырғанда планшеттегі стандартты жол, бөлім және параметр атаулары пішінді қайта қолданбай-ақ бірден жаңартылады.
- Мысалдар: `Бурение` → `Бұрғылау` / `Drilling`, `Описание пород` → `Тау жыныстарының сипаттамасы` / `Rock description`, `Газ C1–C5` → `C1–C5 газы` / `C1–C5 gas`.
- Автоматты бөлінген бағандардың сандық жұрнақтары сақталады: `Бурение 2` → `Бұрғылау 2`.
- Технологиялық параметр атаулары зауыттық пішін сөздігі және Sensors каталогы арқылы аударылады.

## Тау жыныстары

- Каталогтағы тау жыныстарының атаулары визир сызығының мәліметінде, шлам құрамында және жыныс сипаттамасының резервтік мәтінінде белсенді тілге сәйкес көрсетіледі.
- Сипаттамада дәл каталог атауы жазылса, ол да белсенді тілде көрсетіледі.
- Еркін мәтінмен енгізілген геологиялық сипаттамалар мен пайдаланушы атаулары автоматты түрде өзгертілмейді.
