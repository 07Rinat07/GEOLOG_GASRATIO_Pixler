# Импортталған және өзгертілген деректерді сақтау

## Ағымдағы сеанс туралы ақпарат панелі

Қолданбаның төменгі жолағында **Дереккөз → Жоба файлы → Экспорт** тізбегі, ұңғыма, белсенді
деректер жиыны және **Сақталды / Өзгертілді** күйі үнемі көрсетіледі. Дереккөз read-only болып
қалады. Бірінші сақтауға дейін жоба өрісінде **«сақталмаған»**, одан кейін белсенді `.geologpkg`
файлының толық жолы көрсетіледі. Экспорт өрісі LAS бөлек көшірме ретінде жасалатынын түсіндіреді.
Толық кеңесте дереккөз жолы, пішімі, жолдар мен қисықтар саны беріледі.

## Paradox және GS2 импортынан кейін «LAS сақтау»

Paradox DB немесе GS2 тікелей импортталғанда **«LAS сақтау»** әрекеті Dataset сәтті тексеріліп,
тіркелгеннен кейін ғана бірыңғай штаттық экспортты ашады. Import Review болдырылса, диалог
жабылса немесе қате шықса, экспорт іске қосылмайды және жартылай файл жасалмайды. **Ctrl+S**
LAS көшірмесін емес, бүкіл жобаны сақтайды.

## Бағдарламаны жабу

Жұмыс сеансында сақталмаған өзгерістер болса, жабу қорғанысы төрт әрекет ұсынады:

1. **Жобаны сақтау** — деректерді, пішіндерді, безендіруді, аралықтарды және басқа жоба
   нысандарын негізгі `*.geologpkg` форматында сақтайды; ашылған бұрынғы `*.geolog.json`
   үйлесімділік үшін сол форматта қайта сақталады.
2. **LAS көшірмесін экспорттау** — ағымдағы сандық қисықтар мен тақырыптарды жаңа LAS файлына
   сақтайды.
3. **Сақтамау** — ағымдағы өзгерістерді жоғалтып бағдарламаны жабады.
4. **Болдырмау** — бағдарламаға қайтарады.

Күнделікті өсіру — бөлек қорғалған материалдық әрекет: Dataset өзгермей тұрып жұмыс
`.geologpkg` қажет, сәтті append-тен кейін жаңа ревизия автоматты сақталып, алдыңғысы
`.geolog-backups` ішіне жазылады. Бірдей LAS қайталанса, ештеңе сақталмайды. Қалыпты қолмен
енгізілген өзгерістерді **Ctrl+S** арқылы сақтаңыз.

Синхрондау жобаны ашқаннан кейін өзгертсе, қайта жазу блокталады. Ағымдағы сеансты жаңа атаумен
сақтаңыз немесе өзекті файлды ашыңыз. Тексерілген алдыңғы ревизияны **Файл → Қалпына келтіру
көшірмесін қалпына келтіру...** арқылы тек жаңа `.geologpkg` ішіне қайтаруға болады; белсенді
файл қайта жазылмайды.

GeoScape, GeoScape II/GS2 және Paradox бастапқы файлдары автоматты түрде қайта жазылмайды: олар
үшін жобаны немесе жаңа LAS файлын пайдаланыңыз. Бастапқы LAS-пен жұмыс істегенде де бағдарлама
әрқашан атау мен орынды таңдау терезесін ашады; әдепкі атау `original_edited.las` түрінде беріледі.

## Сақталған файлды табу

Жоба немесе LAS сәтті сақталғаннан кейін бағдарлама толық жолды көрсетіп, файл орналасқан қалтаны
ашуды ұсынады. Жобаны алғаш сақтау және **Басқаша сақтау…** командасы әрқашан қалта мен атауды
сұрайды. Қалыпты **Ctrl+S** бұрын таңдалған жоба файлын қайта жазады.

LAS экспорты жобаны сақтауды алмастырмайды: LAS пішіндерді, безендіруді, суреттерді,
шламограмманы, ЛБА-ны, интерпретация аралықтарын және басқа жоба қабаттарын сақтамайды.
