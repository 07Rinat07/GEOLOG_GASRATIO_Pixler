# GEOLOG GASRATIO@Pixler 0.7.67 — параметр атауы бар ықшам шкалалар

## Не өзгерді

- Сандық қисықтардың тақырыптарынан артық жалпы **«Шкала»** жазуы алынды.
- Сызғыш енді жергіліктендірілген параметр атауымен және өлшем бірлігімен тікелей белгіленеді,
  мысалы **«Қашауға түсетін жүктеме · т»**.
- Қисық атауын қайталайтын бөлек жол жойылды. Бір параметр блогының биіктігі 58-ден 44 px-ге
  азайды: тақырыптың тік кеңістігінің 14 px-і немесе шамамен 24%-ы үнемделеді.
- Өңделетін минимум/бірлік/максимум, автоматты диапазон, баптау батырмасы, міндетті шеткі мәндер,
  тор бөліністері, сызықтық/логарифмдік режим және тек толық жолдар бойынша ішкі айналдыру сақталды.
- Өзгеріс ортақ `TabletTrackWidget` ішінде орындалды, сондықтан барлық зауыттық, дайын және
  пайдаланушы пішіндеріне әр үлгіні қолмен түзетпей қолданылады.

## Үйлесімділік

- Project format — `v20`.
- Form schema — `v8`.
- Tablet layout — `v18`.
- Бар пішіндер, ендер, диапазондар, бірліктер, стильдер және байланыстар қайта жазылмайды.
- Түбірлік `README.md` қысқа күйінде қалды және өзгертілмеді.

## Тексеру

Регрессиялық тесттер 44 px толық жол геометриясын, сызғыштағы параметр атауын, ескірген
локализация кілтінің жойылуын, басқару батырмаларының сақталуын, RU/KK/EN құжаттарының
сәйкестігін және нұсқа келісімін тексереді. Толық визуалды Qt-тексеру үшін PySide6 және
pyqtgraph орнатылған Windows ортасы қажет.
