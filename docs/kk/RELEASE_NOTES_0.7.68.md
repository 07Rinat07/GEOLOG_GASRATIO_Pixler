# GEOLOG GASRATIO@Pixler 0.7.68 — анықтамалық белгілерін еркін созу

## Не өзгерді

- Кірістірілген анықтамалық белгісі аннотация жақтауын толық толтырады.
- Сол және оң маркерлер тек енді, жоғарғы және төменгі маркерлер тек биіктікті өзгертеді.
- Бұрыштық маркерлер екі өлшемді еркін өзгертіп, белгіні ұзын, жалпақ, биік немесе ықшам етуге
  мүмкіндік береді.
- Өлшемді өзгерту кезінде **Shift** ұстап тұру бастапқы пропорцияны сақтайды.
- Қалыпты енгізілген суреттер мен фотосуреттер бұрмаланбай сыйғызылады.

## Сақтау және шығару

Соңғы ен мен биіктік бар аннотация геометриясын қолданады. Бір аяқталған қимыл бір Undo/Redo
операциясы болып қалады. **Ctrl+S** өлшемдерді сақтайды, қайта ашу оларды қалпына келтіреді, ал экран,
preview, PDF және физикалық баспа бірдей созылған белгіні көрсетеді.
