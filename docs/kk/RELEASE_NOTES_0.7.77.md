# GEOLOG GASRATIO@Pixler 0.7.77 — WITS0 live monitor

## Кезеңнің мақсаты

0.7.77 нұсқасы WITS0 интеграциясының E кезеңінің негізгі бөлігін аяқтайды. Growing
`AcquisitionDataset` және append-only `AcquisitionSession` үстінде read-only
`AcquisitionLiveView` проекциясы мен **Монитор** қойындысы қосылды.

## Ағымдағы мәндер

Ағымдағы мәндер кестесі таңдалған арналарды, соңғы жарамды мәнді, бірлікті және сапа күйін
көрсетеді. Соңғы жолда арна мәні болмаса, алдыңғы дұрыс мән экранда қалады, бірақ «жаңа мән жоқ»
деп белгіленеді. `good`, `missing`, `invalid`, `source_gap` және `stale` күйлері қолданылады.

## Уақыт және тереңдік графиктері

- нақты time/depth Dataset index тікелей қолданылады;
- time-index Dataset үшін тереңдік осі расталған `HOLE_DEPTH`, `BIT_DEPTH`, `MD`, `GAS_DEPTH`
  немесе семантикалық depth-арнадан read-only түрде жасалады;
- depth-index Dataset үшін UTC уақыт осі `AcquisitionRecord.received_at` арқылы жасалады;
- туынды ось Dataset өзгертпейді және жобаға жазылмайды;
- acquisition тоқтатылмай, көрсетілетін арналарды таңдауға болады.

## Live, pause-view және тарих

Auto-follow терезенің оң шекарасын соңғы нүктеде ұстайды. **Көрсетуді кідірту** тек көрінетін
жолдар санын бекітеді, ал `Wits0AcquisitionRuntime` деректерді қабылдауды, қалыпқа келтіруді және
жазуды жалғастырады. Жалғастырған кезде монитор ағымдағы соңына өтеді. Auto-follow өшірілгенде
масштабтау мен жылжыту тарихи терезені анықтайды.

## Downsampling және сапа маркерлері

Әр көрінетін қисық NaN үзілістерін сақтайтын және нүктелер санын шектейтін peak-preserving
`select_visible_samples()` алгоритмін қолданады. График source sequence үзілістерін, осьтің үлкен
аралықтарын, invalid source values және жоқ мәндер диапазондарын көрсетеді.

`AcquisitionRecord.source` ішінде sequence status, raw SHA-256 және әр WITS `record/item` үшін
құрылымдық quality-кодтар сақталады.

## Үйлесімділік және тексеру

Project format — **v20**, form schema — **v8**, tablet layout — **v18**. Migration қажет емес.
50% ықшам бағандар, дайын 48/80 ендері, барлық дайын және пайдаланушы пішіндері, Пішін жасау,
Пайдаланушы пішінін сақтау, қайталанатын және бос орын атауларын қорғау, Ctrl+S және қайта ашу
өзгеріссіз қалады.

Толық Qt runtime тексеруі үшін PySide6/pyqtgraph бар Windows ортасы және нақты anonymized GSWITS
raw stream қажет. Кідірту тек көрсетілімге әсер етеді және controlled close орнына қолданылмайды.
