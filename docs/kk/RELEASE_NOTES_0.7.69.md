# GEOLOG GASRATIO@Pixler 0.7.69 — жоғарғы панель әрқашан терезе ішінде

## Сыртқы монитордағы панельді түзету

- Оң жақтағы **«Пішінді өңдеу»** пәрмені еннің жуық шегіне енді тәуелді емес.
- Панель ені Qt жүйесіндегі жергіліктендірілген батырмалардың нақты логикалық өлшемдері бойынша
  есептеледі.
- Орын жетпегенде алдымен екінші дәрежелі батырмалардың жазулары жасырылады.
- Өте ықшам режим де сыймаса, маңызы төмен пәрмендер **«⋯»** мәзіріне көшеді, ал өңдеу пәрмені
  оң жақта көрініп қалады.
- Есептеу терезе өлшемі, жүйелік қаріп, стиль, DPI, монитордың жұмыс аймағы өзгергенде және
  терезе ноутбук пен сыртқы монитор арасында ауысқанда орындалады.
- Windows метрикалары кеш жаңарған жағдайға арнап экран ауысқаннан кейін бірден және кідіртілген
  тексеру жасалады.

## Ықшам панельді пайдалану

Пәрмендер көшірілген кезде **«⋯»** батырмасын басыңыз. Мәзірде Басты бет, LAS редакторы, Пішіндер
кітапханасы, Конструктор, ашу/импорт, сақтау, қарындаш және визир сызығы әрекеттері қалады. Перне
тіркесімдері мен негізгі мәзірлер өзгермейді.

## 0.7.68 мүмкіндіктері сақталды

Белгілерді ені мен биіктігі бойынша еркін созу, **Shift** арқылы пропорцияны сақтау, Undo/Redo,
**Ctrl+S**, жобаны қайта ашу, preview, PDF және басып шығару өзгеріссіз қалды.
