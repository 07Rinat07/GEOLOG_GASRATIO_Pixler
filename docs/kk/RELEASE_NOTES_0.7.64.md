# 0.7.64 — пішін жасау кезіндегі атаулар анықтамалығы

**«Пішін жасау»** командасы енді барлық кірістірілген және пайдаланушы пішіндері бар жеке
терезені ашады. Іздеу, атау, ось түрі және шығу тегі көрсетіледі. Пішін таңдалғанда оң жақта
сипаттама, көрінетін бағандар мен сақталған ендер, жолдар және параметрлер саны, сондай-ақ
байланыстырылған қисық мнемоникалары беріледі.

Жаңа атау сол терезеде **«Тереңдік»** немесе **«Уақыт»** осімен бірге енгізіледі. Кездейсоқ бос
орындар жойылып, қайталанған ішкі бос орындар біріктіріледі. Бар атаумен толық сәйкестік регистр
мен артық бос орындарға қарамастан бұғатталады.

Қолданыстағы қорғалған үлгілер жиыны өзгеріссіз қалды; MASTERLOG қайталама үлгісі қосылмады.
0.7.63 ықшам ендері сақталады:
стратиграфия, литология, шламограмма, кальциметрия, ЛБА және тереңдік 40% азайтылған және 48 px
минимумын қолданады; қалыпты графиктер мен мәтін 80 px минимумын сақтайды.

Құжаттама, нұсқаулықтар, күй, жоспар және тесттер орыс, қазақ және ағылшын тілдерінде жаңартылды.
Project format v20, form schema v7 және tablet layout v17 болып қалады.
