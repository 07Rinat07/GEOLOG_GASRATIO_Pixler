# GEOLOG GASRATIO@Pixler 0.7.92

## Планшет бағандарының ықшам атаулары

- **Стратиграфия** және **Шламограмма** сияқты ұзын атаулар 90° бұрылып, бір жолмен салынады және қиылмай толық көрінуі үшін қаріп автоматты түрде дәл бейімделеді.
- Windows қаріптері мен DPI айырмашылықтарында мәтін толық көрінуі үшін бұрылған тақырып жолағы 88-ден 96 px-ге ұлғайтылды.
- **ЛБА** үш әріптен тұратындықтан, барлық дайын және пайдаланушы пішіндерінде әдепкіде көлденең көрсетіледі.
- Тереңдік/Уақыт, Стратиграфия, Литология, Шламограмма және Кальциметрия тік ықшам режимде қалады.

## Пішін үйлесімділігі

- Project format: `v21`.
- Form schema: `v11`.
- Tablet layout: `v21`.
- Бұрынғы form v8, tablet v18 және 0.7.91 пішіндері автоматты түрде жаңартылады.
- Ықшам бағандар ені 50% азайтылып, ең аз 48 px сақталады; кәдімгі қисықтар үшін минимум 80 px.

## Пішіндермен жұмыс

**Пішін жасау** және **Пайдаланушы пішінін сақтау** командалары өзгерген жоқ. Кітапханада барлық дайын және пайдаланушы пішіндері көрінеді; қайталанатын атау регистр мен артық бос орын ескерілмей тексеріледі.

Негізгі іске қосу командасы: `python -m geoworkbench.app.main`.
