# 0.7.63 — ықшам геологиялық бағандар және кірістірілген пайдаланушы MASTERLOG пішіні

0.7.63 нұсқасы қалыпты қисық графиктер мен мәтін бағандарын тарылтпай, планшетте көбірек
көлденең орын босатады. Барлық кірістірілген тереңдік пішіндерінде **Стратиграфия**,
**Литология**, **Шламограмма**, **Кальциметрия**, **ЛБА** және **Тереңдік** бағандарының
бастапқы ені 40% азайтылды. Бұл түрлер үшін минимум 48 px, ал қисықтар мен мәтін үшін қауіпсіз
минимум 80 px болып қалады.

Ескі пайдаланушы пішіндері мен сақталған планшет орналасулары ашылған кезде автоматты түрде
көшіріледі. Тек көрсетілген геологиялық бағандар ықшамдалады; қисықтар мен мәтін ені өзгермейді.
Сақтағаннан кейін form schema v7 және tablet layout v17 қолданылады, сондықтан келесі ашуларда
қайта тарылту болмайды.

Тексерілген пайдаланушы орналасуы қолданбаға қорғалған кірістірілген
**«MASTERLOG — геологиялық-геохимиялық пішін»** үлгісі ретінде қосылды. Өңдеу үшін пайдаланушы
көшірме жасайды, ал қолданбаның бастапқы үлгісі өзгермейді. «Нақты өлшем» баспа режимі сақталған
ықшам пропорцияларды сақтайды, ал «Бағандарды автотаңдау» параққа сәйкес ендерді қайта бөледі.

RU/KK/EN нұсқаулықтары енді, қолмен өлшем өзгертуді, көшіруді, сақтау мен қайта ашуды, баспаны
және кірістірілген пайдаланушы үлгісін бірдей түсіндіреді. Регрессиялық тесттер ен шектерін,
зауыттық пішіндерді, ескі пайдаланушы пішіндерін, layout көшіруін және MASTERLOG үлгісін тексереді.

Жоба форматы v20 болып қалады. Пішін схемасы v6-дан v7-ге, планшет форматы v16-дан v17-ге
көтерілді. Түбірлік README қысқа күйінде қалды және өзгертілмеді.
