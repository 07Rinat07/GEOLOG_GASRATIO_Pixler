# GeoScape / Borland Paradox DB импорты

## Мақсаты және ашу

Импорттаушы GeoScape/Borland Paradox кестелерін стандартты `Dataset` моделіне түрлендіреді.
**Файл → Импорттау → GeoScape / Paradox DB**, әмбебап импорт немесе `.db` drag-and-drop
қолданыңыз. Кеңейтімге сенім артылмайды: алдымен SQLite, содан кейін шектелген Paradox бинарлық
құрылымы тексеріледі. DB/PX/TV/FAM бастапқы файлдары тек оқу режимінде ашылады.

`sample.db` үшін `sample.PX`, `sample.TV` және `sample.FAM` регистрге тәуелсіз ізделеді.
Қосымша файлдың болмауы ескертіледі, бірақ негізгі DB импорты тоқтамайды.

## Қауіпсіздік және ресурстар

Массивтер бөлінбей тұрып header, record size, fields, blocks, жарияланған capacity және жалпы
memory budget тексеріледі. Нөлдік field, қайшы counter, кесілген block және лимиттен асу
қабылданбайды. Оқу, талдау және `Dataset` жасау тоқтатылатын worker ішінде орындалады; қате немесе
терезені жабу жартылай тіркелген dataset қалдырмайды.

## Import Review

Терезе форматты, нұсқаны, өлшемді, жол/өріс санын және қосымша файлдарды көрсетеді. Пайдаланушы
арналарды, LAS mnemonic, сипаттама, бірлік, NULL және белсенді TIME/DEPTH index таңдайды. Preview
тек алғашқы және соңғы 20 жолды оқиды. Екіұшты index автоматты қолданылмайды.

OLE/Delphi Automation date, Unix timestamp және салыстырмалы секунд/миллисекунд қолдау табады.
`TIME` индексі жасалып, бастапқы сан `<арна>_RAW` ретінде сақталады.

## Арналар, профильдер және QC

Белгісіз `Sxxx` болжанбайды. Расталған mapping сөздікте сақталады; профиль schema SHA-256,
indexes, mappings, NULL және өңдеу ережелерін ұстап, тек құрылым толық сәйкес болғанда
қолданылады.

Бос жол/арна, NaN/Infinity, ауытқу, қайталанатын, кері немесе теріс depth, секіру және chronology
тексеріледі. Қайталау әдепкіде сақталады; first/last/mean/median тек анық таңдалады. Барлық түзету
мен жол саны provenance ішінде жазылады.

## Нақты қадам және ресемплинг

GeoScape 0,2 м номиналды торы source нақты қадамынан бөлек көрсетіледі. LAS `STEP` тек бар жолдарды
сипаттайды. 0,2 м туынды торы тек **LAS Editor → Тереңдік қадамын өзгерту…** арқылы жасалады;
бастапқы DB және импортталған `Dataset` өзгермейді.

## LAS, TIME → DEPTH және batch

Depth LAS `DEPT.M`, time LAS `TIME.SEC` қолданады; `STRT/STOP/STEP` деректерден есептеледі.
TIME → DEPTH first/last/mean/median/min/max, nearest немесе linear әдісімен бөлек туынды dataset
жасайды.

**Құралдар → DB → LAS пакеттік түрлендіру** файл/каталог, рекурсивті іздеу, профиль,
`{source_name}_{mode}.las`, overwrite protection, progress, cancel және JSON журналын қолдайды.
Екіұшты файл **«Баптау қажет»** күйін алады.

## Шектеулер

Синтетикалық fixtures `NUMBER`, `LONG` және Alpha, Date, Short, Logical, Time, Timestamp,
AutoIncrement, BCD, Bytes/Blob шектелген декодерлерін қамтиды. Далалық тексеру тек
құпиясыздандырылған кестелерде жасалады; мұндай файлдар мен conversion outputs Git ішінде
сақталмайды.
