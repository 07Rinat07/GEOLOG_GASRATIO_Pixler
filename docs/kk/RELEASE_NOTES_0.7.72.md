# GEOLOG GASRATIO@Pixler 0.7.72 — native QToolBar-дан тыс панельдер және белгіні іс жүзінде шектеусіз жіңішкерту

## Интерфейсті бейімдеу

- Негізгі командалар қатары және **«Пішінді өңдеу (F4)»** қатары енді `QToolBar` емес және `QMainWindow` native toolbar-area ішінде орналаспайды.
- Екі қатар да жұмыс аймағының үстіндегі кәдімгі `QFrame` контейнерлері болып, орталық аймақтың нақты енімен физикалық шектеледі; Qt жүйелік кеңейту көрсеткісі енді қолданылмайды.
- Батырма күйінің өзгеруі, F4 қосылуы, ноутбук пен сыртқы монитор арасында ауысу немесе DPI өзгеруі енді терезенің минимал енін үлкейте алмайды.
- Қосымша қорғаныс негізгі терезенің минимал өлшемін белсенді монитордың жұмыс аймағымен шектейді.
- Оң жақтағы **«Пішінді өңдеу»** командасы терезе ішінде қалады; маңыздылығы төмен командалар белгішелерге және **`⋯`** мәзіріне өтеді.

## Графиктегі белгілер

- Белгінің сақталатын геометриясындағы практикалық жіңішкерту шегі `0,01` логикалық пиксельге дейін төмендетілді; экранда бұл құрылғының бір пиксельдік ең жіңішке көрінетін сызығына сәйкес келеді.
- Ені мен биіктігі тәуелсіз өзгереді: бүйірлік маркерлер бір осьті, бұрыштық маркерлер екі осьті өзгертеді; **Shift** пропорцияны сақтайды.
- Өте жіңішке белгі үшін кемінде `18×18 px` ыңғайлы жеке таңдау рамкасы көрсетіледі; ол белгінің нақты өлшемін өзгертпейді және геометрия ретінде сақталмайды.
- Жіңішке белгіні **Ctrl+S** арқылы сақтап, жобаны қайта ашқаннан кейін қайта таңдап, созуға және жылжытуға болады.
- Қалыпты суреттер, түсініктемелер және выноскалар `40×24 px` қауіпсіз минимумын сақтайды.

## Қосымша түзетулер

- Бір `ResolvedReportDefinition` қолданатын CSV/XLSX енді белсенді сандық TIME index мәнін дәл
  resolved жолдардан, бірінші бағанда TIME және бейтарап interval metadata арқылы экспорттайды.
- Аралық статистикасының overlay панелі resize-дан кейін қолмен жылжытуға жеткілікті бос аймақ
  сақтайды.
- Қайталанатын UI import модульдері жойылды; бес дереккөздің бәрі ортақ
  `DatasetImportJobExecutor` және Import Review ағынын қолданады.

Project format `v20`, form schema `v8`, tablet layout `v18` болып қалады.
