form schema **v8** және tablet layout **v18** қолданады.

- [x] Пішіндер кітапханасы, жасау және сақтау үшін бір толық реестр қолдану;

- [x] негізгі және F4 панелін бейімдеп, оң жақ ауыстырғыштың қиылуына жол бермеу;
- [x] қауіпсіз жою аймағы және растауы бар **«Диагностика деректерін тазарту…»** командасын қосу;

## Келесі кезең

- [ ] Windows жүйесінде 900, 1366, 1600, 1920 px ендерінде және 100–150% масштабта қалыпты/ықшам

- [ ] нақты профильде кітапхана, жасау және сақтау терезелеріндегі пішін құрамының бірдей екенін растау;

Скриншоттағы терезе енінде **«Өңдеу»** сөзі мен батырма оң жақ шекарадан шықпайды. Қалыпты
кітапхана сақтау терезесіндегідей 18 зауыттық пішінді көрсетеді. Диагностика тазартылғаннан кейін
журналдар қайта құрылады, ал жобалар мен пайдаланушы деректері өзгермейді.
