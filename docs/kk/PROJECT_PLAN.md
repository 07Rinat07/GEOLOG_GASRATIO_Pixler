# Жоба жоспары

## Жаңа бағыт: GeoScape II GS2 импорты

- [x] `.gs2` ZIP контейнерін қауіпсіз тану, тексеру және уақытша ашу;
- [x] `GS2.mdb`, `GS2#*.db`, қауіпті жолдар, көшірмелер және ашу лимиттерін тексеру;
- [x] GS2 форматын әмбебап импортқа, мәзірге және drag-and-drop әрекетіне қосу;
- [x] read-only ACE/ODBC арқылы `GS2.mdb` ішіндегі `WELLS`/`FORMULAS` деректерін диагностикамен оқу;
- [x] СГ-8 үлгісіндегі барлық `GS2#*.db` үшін Paradox 7.x форматын растау;
- [x] таңдалған кестені TIME/DEPTH, нақты қадам, provenance және QC арқылы импорттау;
- [x] таңдалған кестені `Dataset` және Import Review ағынына беру;
- [x] схема мен үздіксіздікті тексеріп, көп бөлікті TIME кестелерін автоматты біріктіру;
- [x] `FORMULAS.RESGID=N → SN` байланысын жасап, Sensors атаулары/бірліктері мен provenance қосу;
- [x] бастапқы торды сақтау, 0,2 м торын тек айқын resampling операциясымен жасау;
- [ ] нәтижені GeoScape LAS/Excel эталондық экспортымен салыстыру.

Қазіргі кезең кестені немесе біріктірілген TIME сериясын, ұңғыма паспортын және дәлелденген
формула атауларын қосады. Келесі кезең — өзге нұсқа fixtures және LAS/Excel салыстыруы.



## 0.7.71 нұсқасында орындалды

Сыртқы мониторда F4/батырмалардан кейін интерфейстің оңға кеңеюі түзетілді, екі панельге терезе ені бойынша қатаң шектеу қосылды және белгілер үшін жасырын 40×24 px минимум жойылды. Геометрияны сақтау және RU/KK/EN құжаттары тексерілді.

2026 жылғы 25 шілдеге өзекті. **0.7.71** нұсқасы project format **v20**, form schema **v8**, tablet layout **v18** пайдаланады.

- панель құрамы мен өте кіші белгі геометриясына регрессиялық тексерулер қосылды.

form schema **v8** және tablet layout **v18** қолданады.
