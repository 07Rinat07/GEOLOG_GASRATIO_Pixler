# GEOLOG GASRATIO@Pixler жобасының жоспары

2026 жылғы 25 шілдеге өзекті. **0.7.67** нұсқасы project format **v20**,
form schema **v8** және tablet layout **v18** пайдаланады.

## Орындалды

- [x] әр сандық қисық тақырыбынан қайталанатын **«Шкала»** жазуын алып тастау;
- [x] сызғышты параметр атауымен және бірлігімен белгілеу, мысалы **«Қашауға түсетін жүктеме · т»**;
- [x] диапазон мен `A`/`⚙` командаларын жоғалтпай блокты 58-ден 44 px-ге азайту;
- [x] ортақ рендерер арқылы барлық зауыттық, дайын және пайдаланушы пішіндеріне қолдану;
- [x] толық жолдар бойынша айналдыруды және project v20 / form v8 / tablet v18 үйлесімділігін сақтау;
- [x] RU/KK/EN құжаттары мен регрессиялық тесттерді жаңарту.

## Келесі кезең

- [ ] Windows-та 80, 120, 160 және 250 px жолақ ендерінде тақырыптарды визуалды тексеру;
- [ ] ұзын жергіліктендірілген атаулардың оқылуын және көп нүктемен дұрыс қысқаруын растау;
- [ ] пайдаланушы қабылдауынан кейін бекітілген жоба жоспарын жалғастыру.

## Қабылдау өлшемі

Жалпы **«Шкала»** жазуының орнына әр сызғыш өз параметрінің атауын көрсетеді. Блокта өңделетін
минимум, бірлік, максимум, `A`, `⚙`, шеткі мәндер және бөліністер қалады. Ешбір зауыттық, дайын
немесе пайдаланушы пішінін қолмен жаңарту талап етілмейді.
