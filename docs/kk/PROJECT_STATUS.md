# Жоба күйі

2026 жылғы 25 шілде. Пакет нұсқасы: **0.7.64**. Project format: **v20**,
form schema: **v7**, tablet layout: **v17**.

## 0.7.64 нұсқасында аяқталды

- 0.7.63 өзгерістері сақталды: стратиграфия, литология, шламограмма, кальциметрия, ЛБА және
  тереңдік ықшам бағандары, form schema v6 → v7 және tablet layout v16 → v17 көшірулері;
- қорғалған үлгілердің қолданыстағы жиыны MASTERLOG қайталама үлгісін қоспай сақталды;
- **«Пішін жасау»** командасы енді атауға арналған шағын жабық өрісті ашпайды;
- жаңа терезеде барлық кірістірілген және пайдаланушы пішіндері, іздеу, ось және шығу тегі көрінеді;
- таңдалған пішін үшін сипаттама, бағандар мен ендер, жолдар, параметрлер және мнемоникалар беріледі;
- қайталанатын атау әріп регистрі мен қайталанған бос орындарға қарамастан бұғатталады;
- жаңа атаудағы кездейсоқ бос орындар автоматты түрде қалыпқа келтіріледі;
- пайдаланушы нұсқаулықтары мен мүмкіндіктер карталары орыс, қазақ және ағылшын тілдерінде
  синхрондалды;
- түбірлік README қысқа күйінде қалды және техникалық релиз тарихын қамтымайды.

## Тексеру

Атауды қалыпқа келтіру және қайталануды анықтау тесттері, жаңа терезенің source-contract тесті,
пішіндерді көрсету мен қайталанатын атауды бұғаттаудың GUI сценарийлері, MASTERLOG қайталама
үлгісінің жоқтығы және ықшам ендер тексерілді. Толық визуалды Qt/UI, HiDPI, PDF және физикалық printer-gate
PySide6, pyqtgraph және lasio орнатылған Windows ортасында орындалады.

## Келесі кезең

Windows smoke-test аяқталғаннан кейін read-only offline WITSML 2.1 inventory және mapping
fixtures жоспарын жалғастыру.
