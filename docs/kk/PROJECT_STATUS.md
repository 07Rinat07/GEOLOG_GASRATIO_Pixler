# GEOLOG GASRATIO@Pixler жобасының күйі

2026 жылғы 25 шілде. Пакет нұсқасы: **0.7.65**. Project format: **v20**,
form schema: **v8**, tablet layout: **v18**.

## 0.7.65 нұсқасында аяқталды

- **«Пішін жасау»** және **«Пайдаланушы пішінін сақтау»** командаларындағы ескі шағын атау өрісі
  жойылды; екі команда да барлық дайын, зауыттық және пайдаланушы пішіндерін, іздеуді және толық
  құрамды көрсетеді;
- қайталанатын атау әріп регистрі мен қайталанған бос орындарды елемей бұғатталады, ал өңделетін
  пайдаланушы пішінінің үстіне сақтау тек анық ескертуден кейін жаңа ревизия жасайды;
- ескі атауы расталған төрт жергілікті пішін автоматты түрде түзетіліп, `forms/ready` бөліміне
  көшіріледі және бөлек қайталама MASTERLOG үлгісін жасамай дайын шаблон ретінде қорғалады;
- нақты JSON құрылымы: бағандар, жолдар, параметрлер, шкалалар, стильдер және рет сақталады;
- стратиграфия, литология, шламограмма, кальциметрия, ЛБА және тереңдік көшіру кезінде **50%**
  азаяды, минимум **48 px**, ал басқа графиктер үшін минимум **80 px**;
- v7 және одан ескі пішіндер **v8**, v17 және одан ескі планшеттер **v18** нұсқасына бір рет өтеді;
- құжаттама, нұсқаулықтар және release notes RU/KK/EN тілдерінде синхрондалды.

## Тексеру

Модель, codec/repository, көшіру, naming, layout/print және source-integrity тесттері өтті.
Автоматты аудит локализацияланған құжаттар жиынын, Markdown сілтемелерін, интерфейстің 1881 кілтін,
пакет нұсқасын, белгілерді сақтауды, ықшам ендерді және пішінді жасау/сақтау сценарийін тексереді.
Толық визуалды Qt/UI тексеруі PySide6, pyqtgraph және lasio бар Windows ортасын талап етеді.

## Жергілікті пішіндерді тасымалдау шектеуі

Берілген бастапқы ZIP ішінде Windows профиліндегі төрт пішіннің JSON файлдары жоқ. Сол компьютерде
олар автоматты түрде талданып, дайын пішіндерге көшіріледі. Басқа таза компьютерге орнату үшін
олардың JSON файлдарын жергілікті кітапханадан экспорттау немесе көшіру қажет.
