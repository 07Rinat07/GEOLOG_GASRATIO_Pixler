# GEOLOG GASRATIO@Pixler жобасының күйі

2026 жылғы 25 шілде. Пакет нұсқасы: **0.7.66**. Project format: **v20**,
form schema: **v8**, tablet layout: **v18**.

## 0.7.66 нұсқасында аяқталды

- қалыпты Пішіндер кітапханасы және жасау/сақтау терезелері бір каталогқа көшірілді; барлық жерде
  дайын, барлық **18 зауыттық** және пайдаланушы пішіндері көрінеді;
- кітапхананың қысқартылған тізімі мен сақтау терезесінің толық тізімі арасындағы сәйкессіздік жойылды;
- негізгі панель және **«Пішінді өңдеу (F4)»** панелі терезе еніне бейімделеді: екінші дәрежелі
  командалар белгіше режиміне өтеді, ал оң жақ ауыстырғыш көрініп қалады;
- растауы, журналдар/есептерді қауіпсіз тазартуы және журнал жүргізуді автоматты жалғастыруы бар
  **«Диагностика деректерін тазарту…»** командасы қосылды;
- импорт диагностикасы әр түр үшін соңғы 30 есеппен шектелді;
- нұсқаулықтар мен release notes орыс, қазақ және ағылшын тілдерінде жаңартылды.

## 0.7.65 нұсқасынан сақталғаны

Пішін атауының толық терезесі, төрт жергілікті пішінді көшіру, ықшам геологиялық бағандар,
form schema v8 және tablet layout v18 өзгеріссіз қалады.

## Тексеру

Бірыңғай каталог, панель бейімделуі және диагностика тазартуы үшін регрессиялық тесттер қосылды.
Толық визуалды Qt/UI тексеруі PySide6 және pyqtgraph бар Windows ортасын талап етеді.
