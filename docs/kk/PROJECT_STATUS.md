# GEOLOG GASRATIO@Pixler жобасының күйі

2026 жылғы 25 шілде. Пакет нұсқасы: **0.7.67**. Project format: **v20**,
form schema: **v8**, tablet layout: **v18**.

## 0.7.67 нұсқасында аяқталды

- әр сандық қисық тақырыбынан қайталанатын жалпы **«Шкала»** жазуы алынды;
- инженерлік сызғыш параметр атауымен және бірлігімен белгіленеді, мысалы
  **«Қашауға түсетін жүктеме · т»**;
- атаудың бөлек жолы жойылып, толық параметр блогы 58-ден 44 px-ге азайды және тік кеңістіктің
  шамамен 24%-ын үнемдейді;
- минимум/бірлік/максимум, автоматты диапазон, баптау, бөліністер және шеткі мәндер сақталды;
- ортақ `TabletTrackWidget` жаңа тақырыпты project format, form schema немесе tablet layout
  өзгертпей барлық зауыттық, дайын және пайдаланушы пішіндеріне қолданады;
- нұсқаулықтар мен release notes қазақ, орыс және ағылшын тілдерінде синхрондалды.

## 0.7.66 нұсқасынан сақталған

Бірыңғай толық пішіндер каталогы, бейімделетін жоғарғы панельдер, диагностиканы қауіпсіз тазарту,
импорт есептерінің санын шектеу, толық сақтау терезесі және ықшам геологиялық бағандар көшіруі
өзгеріссіз қалды.

## Тексеру

44 px геометриясына, сызғыштағы параметр атауына, ескірген **«Шкала»** кілтінің жойылуына,
`A`/`⚙` батырмаларына және RU/KK/EN құжаттарына регрессиялық тексерулер қосылды. Толық визуалды
Qt/UI тексеруі үшін PySide6 және pyqtgraph бар Windows ортасы қажет.
