# GEOLOG GASRATIO@Pixler 0.7.70 — бекітілген бейімделетін панель және белгіні еркін жіңішкерту

## Жоғарғы панель

- Негізгі панель енді бір шектелген бейімделетін контейнердің ішінде орналасады. Монитор немесе DPI ауысқаннан кейін `QToolBar` жүйелік кеңейту батырмасы пайда болып, оң жақ пәрменді терезеден шығара алмайды.
- **«Пішінді өңдеу»** пәрмені қолжетімді терезе енінің ішінде оң жаққа бекітілген.
- Орын жетпесе, жазулар белгішелерге ауысады, ал маңыздылығы төмен пәрмендер қолданбаның **`⋯`** мәзіріне өтеді.
- Дәл осы қатар архитектурасы **«Пішінді өңдеу (F4)»** панеліне де қолданылады.
- Терезе өлшемі, жүйелік қаріп, стиль, DPI, жұмыс аймағы немесе монитор өзгергенде орналасу қайта есептеледі.

## Белгі өлшемі

- Кірістірілген анықтамалықтан енгізілген белгіні бұрынғы 48×28 px шектеуінің орнына ені немесе биіктігі бойынша тәуелсіз 2 логикалық пиксельге дейін жіңішкертуге болады.
- Бүйірлік маркерлер бір осьті, бұрыштық маркерлер екі осьті өзгертеді.
- Бастапқы пропорцияны сақтау үшін `Shift` ұстап тұрыңыз.
- Қалыпты суреттер, түсініктемелер және шығарма нысандары қауіпсіз ең кіші өлшемдерін сақтайды.
- Кіші өлшемдер жобада сақталып, қайта ашылғанда қалпына келеді және preview, PDF пен басып шығаруда қолданылады.

Project format `v20`, form schema `v8`, tablet layout `v18` болып қалады.
