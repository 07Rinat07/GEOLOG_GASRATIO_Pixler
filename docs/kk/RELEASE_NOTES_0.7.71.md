# GEOLOG GASRATIO@Pixler 0.7.71 — панель енін қатаң шектеу және белгіні нақты жіңішкерту

## Интерфейс панельдері

- Негізгі панель мен **«Пішінді өңдеу (F4)»** панелі енді терезенің ең аз енін үлкейте алмайды.
- Екі панель де DPI қолданылғаннан кейінгі терезенің нақты логикалық енімен қатаң шектеледі.
- Қайта есептеу F4 панелі көрсетілгенде/жасырылғанда, командалар күйі өзгергенде және Windows метрикалары жаңарғаннан кейін қайталанады.
- Оң жақтағы **«Пішінді өңдеу»** командасы терезе ішінде қалады; қосымша командалар белгішелерге және **`⋯`** мәзіріне өтеді.
- Сыртқы мониторда бірнеше батырманы басқаннан кейін интерфейстің экраннан кең болып кету сценарийі түзетілді.

## Графиктегі белгілер

- Аннотациялардың экрандық және баспа компоновкасындағы жасырын `40×24 px` шектеуі алынды.
- Анықтамалық белгісін ені мен биіктігі бойынша нақты `1×1` логикалық пиксельге дейін жіңішкертуге болады.
- Сол/оң маркер енді, үстіңгі/астыңғы маркер биіктікті, бұрыштық маркерлер екі өлшемді өзгертеді; `Shift` пропорцияны сақтайды.
- Қалыпты суреттер, түсініктемелер және выноскалар үшін қауіпсіз `40×24 px` минимумы сақталады.
- Өте кіші геометрия жобаға сақталып, экранда, preview, PDF және баспада бірдей қолданылады.

Project format `v20`, form schema `v8`, tablet layout `v18` болып қалады.
