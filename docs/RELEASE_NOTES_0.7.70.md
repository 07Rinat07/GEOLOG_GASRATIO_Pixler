# GEOLOG GASRATIO@Pixler 0.7.70 — фиксированная адаптивная панель и свободное сужение значков

## Верхняя панель

- Главная панель теперь размещается внутри одного адаптивного контейнера. Стандартная кнопка переполнения `QToolBar` больше не может появиться после смены монитора или DPI и вытолкнуть правую команду за экран.
- Команда **«Редактирование формы»** закреплена справа внутри доступной ширины окна.
- При нехватке места подписи заменяются значками, а менее приоритетные команды переходят в собственное меню **`⋯`**.
- Та же схема применяется к панели **«Редактирование формы (F4)»**.
- Пересчёт выполняется при изменении размера окна, системного шрифта, стиля, DPI, рабочей области и при переносе окна между мониторами.

## Размер значков

- Значок из встроенного справочника можно сжимать по ширине и высоте независимо до 2 логических пикселей вместо прежнего ограничения 48×28 px.
- Боковые маркеры изменяют одну ось, угловые — обе оси.
- `Shift` сохраняет исходное соотношение сторон.
- Обычные изображения, комментарии и выноски сохраняют безопасные минимальные размеры.
- Малые размеры сохраняются в проекте, восстанавливаются после повторного открытия и используются в preview, PDF и печати.

Project format остаётся `v20`, form schema — `v8`, tablet layout — `v18`.
