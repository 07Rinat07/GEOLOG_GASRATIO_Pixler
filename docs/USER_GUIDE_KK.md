# GEOLOG GASRATIO@Pixler пайдаланушы нұсқаулығы

## 1. Бөлімдердің реті

Интерфейс міндеті бойынша ұйымдастырылған:

- **жұмыс қойындылары** — қисықтар, LAS кестесі және планшет;
- **Құралдар** — «Файлдар / PDF / Калькулятор» терезесі;
- **Басып шығару** — баспа орталығы және интерпретация есептері;
- **Анықтама** — құжаттама, нұсқаулықтар, журналдар және диагностикалық жинақ.

Қызметтік терезелер бөлек ашылады және тұрақты жұмыс қойындыларын алмайды.

## 2. Файлдар, PDF және калькуляторлар

**Құралдар → Файлдар / PDF / Калькулятор** тармағын ашыңыз.

1. Қолдау көрсетілетін файлды таңдап, толық жүктелуін күтіңіз.
2. PDF өңдеу алдында бетті және масштабты тексеріңіз.
3. Түпнұсқа қажет болса, нәтижені жаңа атаумен сақтаңыз.
4. Калькуляторларда кіріс деректерінің өлшем бірліктерін міндетті түрде тексеріңіз.
5. Бос, теріс немесе физикалық мүмкін емес мәндерден алынған нәтижені қолданбаңыз.
6. PyMuPDF немесе Pillow орнатылмаса, негізгі қолданба жұмысын жалғастырады және орнату пәрменін көрсетеді.

## 3. Баспа орталығы

**Басып шығару → Баспа орталығы** тармағын ашыңыз.

1. Ұңғыманы, dataset пен таңдалған аралықты тексеріңіз.
2. Қағазды, бағдарды, жиектерді, масштабты және баспа тақырыбын таңдаңыз.
3. Кең графиктер үшін A4 немесе A3 көлденең бағдарын қолданыңыз.
4. Алдын ала көріністі ашып, барлық бетті тексеріңіз.
5. Графиктердің бөлінбегенін, жазулардың оқылатынын және оң жақ шкаланың баспа аумағында қалғанын тексеріңіз.
6. Алдымен бақылау PDF сақтаңыз. Қағазға басуды PDF қаралғаннан кейін ғана орындаңыз.

Экспорттың сәтті аяқталуы дұрыс орналасуды кепілдемейді. Дайын файлды міндетті түрде ашып тексеріңіз.

## 4. Интерпретация есептері

**Басып шығару → Интерпретация есептері** тармағын ашыңыз.

Қолжетімді есептер:

- **Газ каротажын интерпретациялау** — есептеулер, графиктер, перспективалы аралықтар, Excel, Word, PDF және басып шығару;
- **Кальциметрия және LBA** — бөлек интерпретациялық есеп.

### Газ каротажы есебін дайындау тәртібі

1. Ұңғыма мен деректер жиынын таңдаңыз.
2. C1–C5, ROP, RPM, WOB, BIT/BS және FLOW тексеріңіз.
3. Нормаланған газ көзін таңдаңыз.
4. BIT, ROP_REF, BIT_REF, FLOW_REF және газ жүйесінің тиімділігін баптаңыз.
5. Қолжетімді қисықтарды қайта есептеңіз.
6. DEXP сапасы мен үзіліс себептерін тексеріңіз.
7. Графиктері бар есепті жаңартыңыз.
8. Шкалаларды, бірліктерді, C1–C5 абсолют мәндерін және перспективалы аралықтарды тексеріңіз.
9. Кестелерді бақылау үшін Excel немесе Word сақтаңыз.
10. PDF жасап, оны бірінші беттен соңғы бетке дейін қарап шығыңыз.

Перспективалы аралықтар геолог қорытындысын алмастырмайды.

## 5. Анықтама және диагностика

Кірістірілген нұсқаулық үшін **Анықтама → Құжаттама және нұсқаулықтар** тармағын ашыңыз.

Қате болған жағдайда:

1. әрекеттер ретін және уақытын жазыңыз;
2. бастапқы файлды және ақаулы нәтижені сақтаңыз;
3. журналдар қалтасын ашыңыз немесе диагностикалық жинақ жасаңыз;
4. себеп талданғанша жаппай экспортты қайталамаңыз;
5. әзірлеушіге журналды, жинақты, кіріс файлын және ақаулы беттің суретін беріңіз.
