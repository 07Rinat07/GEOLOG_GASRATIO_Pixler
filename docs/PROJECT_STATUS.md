# Статус проекта GEOLOG GASRATIO@Pixler

Срез: 25 июля 2026 года. Версия пакета: **0.7.67**. Project format: **v20**,
form schema: **v8**, tablet layout: **v18**.

## Завершено в 0.7.67

- из шапки каждой числовой кривой удалена дублирующая общая надпись **«Шкала»**;
- инженерная линейка подписывается названием параметра и единицей, например
  **«Нагрузка на долото · т»**;
- отдельная строка названия удалена, поэтому полный блок параметра уменьшен с 58 до 44 px
  и экономит около 24% вертикального места;
- минимум/единица/максимум, автоматический диапазон, настройки, деления и крайние значения сохранены;
- единый `TabletTrackWidget` применяет новую шапку ко всем заводским, готовым и пользовательским
  формам без изменения project format, form schema или tablet layout;
- инструкции и release notes синхронизированы на русском, казахском и английском.

## Сохранено из 0.7.66

Единый полный каталог форм, адаптивные верхние панели, безопасный сброс диагностики, ограничение
накопления импорт-отчётов, полноценное окно сохранения формы и миграция компактных геологических
колонок остаются без изменения.

## Проверка

Добавлены регрессионные проверки 44 px геометрии, подписи линейки названием параметра, удаления
устаревшего ключа **«Шкала»**, сохранения кнопок `A`/`⚙` и документации RU/KK/EN. Полный
визуальный Qt/UI-прогон требует Windows-окружение с PySide6 и pyqtgraph.
