# Статус проекта

Срез: 25 июля 2026 года. Версия пакета: **0.7.64**. Project format: **v20**,
form schema: **v7**, tablet layout: **v17**.

## Завершено в 0.7.64

- сохранён полный документационный аудит и изменения компактных колонок предыдущих версий;
- сохранён существующий набор защищённых шаблонов без создания дублирующего MASTERLOG-шаблона;
- создание формы перенесено из малого поля ввода в отдельное окно со всеми существующими
  встроенными и пользовательскими формами;
- добавлены поиск, тип оси, источник и подробности выбранной формы: описание, колонки, ширины,
  дорожки, параметры и мнемоники;
- одинаковые названия блокируются без учёта регистра и повторяющихся пробелов;
- случайные пробелы автоматически нормализуются перед сохранением;
- документация и инструкции синхронизированы на русском, казахском и английском языках;
- корневой README сохранён без технического журнала изменений.

## Проверка

Добавлены pure-тесты нормализации имён и дубликатов, source-contract нового диалога, GUI-тесты
списка и валидации, а также проверки отсутствия дублирующего шаблона и компактных ширин. Полный визуальный
Qt/UI, HiDPI, PDF и физический printer-gate остаётся обязательным Windows smoke-test.
