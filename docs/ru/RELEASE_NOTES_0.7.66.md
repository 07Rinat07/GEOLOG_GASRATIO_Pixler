# GEOLOG GASRATIO@Pixler 0.7.66 — единый каталог, очистка диагностики и адаптивные панели

## Что изменено

- **Библиотека форм**, **Создать форму** и **Сохранить пользовательскую форму** теперь используют
  один авторитетный каталог: готовые формы, все **18 заводских** форм и пользовательские формы
  отображаются одинаково во всех окнах.
- Устранено расхождение, при котором полный заводской набор был виден только во время сохранения,
  а обычная библиотека показывала сокращённую подборку.
- Главная верхняя панель и панель **«Редактирование формы (F4)»** получили адаптивный режим. При
  нехватке ширины второстепенные команды становятся кнопками только с иконками, поэтому правый
  переключатель редактирования остаётся внутри окна.
- В меню **Справка** добавлена команда **«Сбросить данные диагностики…»**. Она с подтверждением
  удаляет накопленные журналы и отчёты импорта, после чего журналирование продолжается автоматически.
- Автоматическое хранение отчётов импорта ограничено 30 последними файлами каждого типа.

## Безопасность очистки

Очистка не затрагивает проекты, LAS, пользовательские формы, настройки и экспортированные
пользователем ZIP-пакеты диагностики.

## Совместимость

Project format остаётся **v20**, form schema — **v8**, tablet layout — **v18**.
