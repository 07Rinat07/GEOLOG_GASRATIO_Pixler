# GEOLOG GASRATIO@Pixler 0.7.69 — верхняя панель всегда внутри окна

## Исправление панели на внешнем мониторе

- Правая команда **«Редактирование формы»** больше не зависит от приблизительного порога ширины.
- Ширина панели рассчитывается по реальным размерам локализованных кнопок в логических пикселях Qt.
- При нехватке места сначала скрываются подписи второстепенных кнопок.
- Если даже сверхкомпактный режим не помещается, команды с меньшим приоритетом переносятся в кнопку
  **«⋯»**, а сама команда редактирования остаётся видимой справа.
- Пересчёт выполняется при изменении размера окна, системного шрифта, темы, DPI, рабочей области
  монитора и при переносе окна между ноутбуком и внешним монитором.
- После смены экрана выполняются немедленная и отложенная проверки, чтобы учесть позднее обновление
  метрик Windows.

## Как пользоваться компактной панелью

Когда часть команд перенесена, нажмите **«⋯»**. В меню остаются те же действия: главная страница,
редактор LAS, библиотека форм, конструктор, открытие и импорт данных, сохранение, карандаш и визирная
линия. Горячие клавиши и основные меню продолжают работать без изменений.

## Сохранённые возможности 0.7.68

Свободное растяжение значков по ширине и высоте, пропорциональный режим с **Shift**, Undo/Redo,
сохранение через **Ctrl+S**, повторное открытие, preview, PDF и печать сохранены без изменений.
