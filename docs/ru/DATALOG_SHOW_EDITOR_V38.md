# Отдельные пробы DataLog / MOL — редактор v38

**Статус:** новая функциональность в PR, а не в стабильной версии `main`.

В карточке шлама (общий редактор) и форме «Анализ пробы» появился отдельный блок DataLog с девятью независимыми методами: запах, видимые пятна, прямая флуоресценция UV+, растворительный cut при обычном освещении и под УФ, остаток cut при обычном освещении и под УФ, капиллярная вытяжка при обычном освещении и под УФ.

Для каждого метода можно записать **долю целевой породы, %** (когда это применимо), цвет, яркость/выраженность, распределение, скорость реакции, примечание и QC («Не проверено», «Проверено», «Сомнительно»). Незаполненное поле означает «не исследовано» и не приравнивается к нулю. Для первого этапа допускается одна запись на метод в пределах одной пробы; повторные независимые измерения требуют последующего расширения.

**Старые поля ЛБА и оценки Флоровской сохраняются без изменений.** При открытии старого проекта v37 новая таблица пуста. Баллы ЛБА, cut и residue старого проекта не копируются автоматически в самостоятельные поля DataLog. Новые записи сохраняются только в формате проекта **v38**, и более старая версия приложения может не открыть проект v38. Создавайте резервную копию перед переводом рабочего проекта на новую версию. Сохранение/открытие проверяется автоматическими тестами; надёжность полевой интерпретации требует отдельной приёмки.

Новый редактор **не определяет нефтяные или газовые пласты**, не рассчитывает Sw/пористость и не объединяет наблюдения по глубине с ГТИ/ГИС. Следующий этап: согласованная MD-ось, контроль газового лага, source/QC, совместимость с ГИС-алгоритмами и одобренные геологом заключения.

Правила безопасности: H₂S контролируется только штатными средствами, не по запаху; подтверждение органической флуоресценции требует проверки реагентов, фона бурового раствора, углей и минералов.
