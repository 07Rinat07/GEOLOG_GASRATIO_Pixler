# Статус проекта GEOLOG GASRATIO@Pixler

Срез: 25 июля 2026 года. Версия пакета: **0.7.66**. Project format: **v20**,
form schema: **v8**, tablet layout: **v18**.

## Завершено в 0.7.66

- обычная Библиотека форм и окна создания/сохранения переведены на один каталог; во всех местах
  видны готовые, все **18 заводских** и пользовательские формы;
- удалено расхождение между сокращённым списком библиотеки и полным списком окна сохранения;
- главная панель и панель **«Редактирование формы (F4)»** адаптируются к ширине окна: второстепенные
  команды переходят в режим иконок, а правый переключатель остаётся видимым;
- добавлена команда **«Сбросить данные диагностики…»** с подтверждением, безопасной очисткой
  журналов/отчётов и автоматическим возобновлением журналирования;
- хранение импорт-диагностики ограничено 30 последними отчётами каждого типа;
- инструкции и release notes обновлены на русском, казахском и английском.

## Сохранено из 0.7.65

Полноценное окно именования форм, миграция четырёх локальных форм, компактные геологические колонки,
form schema v8 и tablet layout v18 остаются без изменения.

## Проверка

Добавлены регрессионные тесты единого каталога, адаптации панелей и очистки диагностики. Полный
визуальный Qt/UI-прогон по-прежнему требует Windows-окружение с PySide6 и pyqtgraph.
