# Статус проекта

Срез: 25 июля 2026 года. Версия пакета: **0.7.64**. Project format: **v20**,
form schema: **v7**, tablet layout: **v17**.

## Завершено в 0.7.64

- сохранены изменения 0.7.63: компактные колонки стратиграфии, литологии, шламограммы,
  кальциметрии, ЛБА и глубины, миграции form schema v6 → v7 и tablet layout v16 → v17;
- сохранён существующий набор защищённых шаблонов без отдельного дублирующего шаблона MASTERLOG;
- команда **«Создать форму»** больше не открывает слепое маленькое поле имени;
- новое окно показывает все встроенные и пользовательские формы, поиск, ось и источник;
- для выбранной формы отображаются описание, колонки и их ширины, дорожки, параметры и мнемоники;
- совпадающее название блокируется без учёта регистра и повторяющихся пробелов;
- случайные пробелы в новом названии автоматически нормализуются;
- пользовательские инструкции и карты возможностей синхронизированы на русском, казахском и
  английском языках;
- корневой README оставлен кратким и не содержит технической истории релиза.

## Проверка

Добавлены независимые тесты нормализации и проверки дубликатов названий, source-contract нового
окна, GUI-сценарии отображения форм и блокировки совпадений, а также проверки встроенного
отсутствия дублирующего MASTERLOG-шаблона и компактных ширин. Полный визуальный Qt/UI, HiDPI, PDF и физический
printer-gate выполняется в Windows-окружении с PySide6, pyqtgraph и lasio.

## Следующий этап

После Windows smoke-test продолжить утверждённый план проекта с read-only offline WITSML 2.1
inventory и mapping fixtures.
