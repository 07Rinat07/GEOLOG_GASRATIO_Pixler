# GEOLOG GASRATIO@Pixler 0.7.67 — компактные шкалы с названием параметра

## Что изменено

- Из шапок числовых кривых удалена лишняя общая надпись **«Шкала»**.
- Линейка теперь подписывается непосредственно локализованным названием параметра и единицей,
  например **«Нагрузка на долото · т»**.
- Удалена отдельная дублирующая строка названия кривой. Высота одного блока параметра уменьшена
  с 58 до 44 px: экономится 14 px, то есть около 24% вертикального места шапки.
- Сохранены редактируемые минимум/единица/максимум, автоматический диапазон, кнопка настроек,
  обязательные крайние значения, деления сетки, линейный/логарифмический режим и внутренняя
  прокрутка только по целым строкам.
- Изменение выполнено в общем `TabletTrackWidget`, поэтому действует во всех заводских, готовых
  и пользовательских формах без ручного редактирования каждого шаблона.

## Совместимость

- Project format остаётся `v20`.
- Form schema остаётся `v8`.
- Tablet layout остаётся `v18`.
- Существующие формы, ширины, диапазоны, единицы, стили и привязки не переписываются.
- Корневой `README.md` остаётся кратким и не изменён.

## Проверка

Регрессионные тесты проверяют высоту целой строки 44 px, подпись линейки названием параметра,
удаление устаревшего ключа локализации, сохранение кнопок управления, синхронность документации
RU/KK/EN и контракт версии. Полная визуальная Qt-проверка по-прежнему требует Windows с PySide6
и pyqtgraph.
