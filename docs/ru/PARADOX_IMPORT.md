# Импорт GeoScape / Borland Paradox DB

## Назначение и открытие

Импортёр преобразует таблицы GeoScape/Borland Paradox в стандартный `Dataset`. Используйте
**Файл → Импортировать → GeoScape / Paradox DB**, универсальный импорт или перетащите `.db` в
окно. Расширение не считается доказательством формата: сначала проверяется SQLite, затем
ограниченная бинарная структура Paradox. Исходные DB/PX/TV/FAM открываются только для чтения.

Для `sample.db` автоматически ищутся `sample.PX`, `sample.TV` и `sample.FAM` без учёта регистра.
Отсутствие вспомогательного файла показывается как предупреждение и не блокирует основной DB.

## Безопасность и ресурсы

До выделения массивов проверяются заголовок, размер записи, поля, блоки, объявленная вместимость и
общий memory budget. Нулевые поля, противоречивые счётчики, обрезанные блоки и превышение лимита
отклоняются. Чтение, анализ и создание `Dataset` выполняются в отменяемом worker; ошибка или
закрытие не оставляет частично зарегистрированный набор.

## Import Review

Окно показывает формат, версию, размер, строки, поля и найденный комплект. Можно выбрать каналы,
LAS-мнемонику, описание, единицу, NULL и активный TIME/DEPTH-индекс. Предпросмотр читает только
первые и последние 20 строк. Неоднозначный индекс не применяется автоматически.

Поддерживаются OLE/Delphi Automation date, Unix timestamp и относительные секунды/миллисекунды.
Для времени создаётся индекс `TIME`, а исходное число сохраняется как `<канал>_RAW`.

## Каналы, профили и QC

Неизвестный `Sxxx` не угадывается. Подтверждённые связи задаются словарём, а профиль хранит
SHA-256 схемы, индексы, mappings, NULL и правила обработки и применяется только при полном
совпадении структуры.

Проверяются пустые строки/каналы, NaN/Infinity, выбросы, повторяющаяся, обратная или отрицательная
глубина, скачки и хронология. Повторы по умолчанию сохраняются; first/last/mean/median применяются
только явно. Все исправления и количества строк записываются в provenance.

## Что происходит после импорта

Действие **«Открыть в редакторе»** регистрирует `Dataset` в текущем ещё не сохранённом проекте;
оно не создаёт LAS. При прямом выборе Paradox DB или GS2 действие **«Сохранить LAS»** после
успешной регистрации Dataset открывает один штатный диалог экспорта. Если Import Review отменён,
диалог закрыт или импорт завершился ошибкой, экспорт не запускается и файл не создаётся.
**Ctrl+S** сохраняет проект, а не LAS. Продолжение работы описано в
[рабочем процессе проекта](PROJECT_WORKFLOW.md).

## Фактический шаг и ресемплинг

Номинальная сетка GeoScape 0,2 м показывается отдельно от фактического шага источника.
LAS-заголовок `STEP` всегда описывает существующие строки. Производная сетка 0,2 м создаётся
только явной командой **LAS Editor → Изменить шаг глубины…**; исходный DB и импортированный
`Dataset` не изменяются.

## LAS, TIME → DEPTH и batch

Глубинный LAS использует `DEPT.M`, временной — `TIME.SEC`; `STRT/STOP/STEP` вычисляются по данным.
TIME → DEPTH создаёт отдельный производный набор и предлагает first/last/mean/median/min/max,
nearest или linear.

**Инструменты → Пакетная конвертация DB → LAS** поддерживает файлы/каталоги, рекурсивный поиск,
профиль, `{source_name}_{mode}.las`, защиту от перезаписи, progress, cancel и JSON-журнал.
Неоднозначный файл получает статус **«Требуется настройка»**.

## Временной планшет после импорта

Если доступно абсолютное календарное время, планшет использует `DATETIME` как вертикальную ось. Фактическая ширина колонки даты/времени одинакова для scroll canvas, объединённых групповых заголовков и частичного обновления треков. Dataset, выбранная форма и геологические слои устанавливаются одним render pass, что предотвращает наложение заголовков, обрезку шкал и серые остатки предыдущего планшета.

## Ограничения

Синтетические fixtures покрывают `NUMBER`, `LONG` и ограниченные декодеры Alpha, Date, Short,
Logical, Time, Timestamp, AutoIncrement, BCD и Bytes/Blob. Полевое подтверждение выполняется
только на обезличенных таблицах; такие файлы и результаты конвертации не хранятся в Git.
