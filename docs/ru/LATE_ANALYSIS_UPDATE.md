# Импорт поздних анализов шлама

Поздние лабораторные результаты кальциметрии, ЛБА и заключения можно безопасно добавить к уже сохранённым пробам шлама без повторного импорта исходного LAS.

## Перед началом

- Откройте нужный `.geologpkg` и выберите скважину.
- Проект должен быть уже сохранён на диск: подтверждённые изменения сразу проходят материальное автосохранение.
- Исходный файл анализа не изменяется.

## Поддерживаемые файлы

Команда принимает `CSV`, `TXT`, `XLSX` и `XLSM`. Для CSV/TXT поддерживаются UTF-8 и CP1251, разделитель определяется автоматически. В Excel читается первый лист.

Обязательны верхняя и нижняя глубина интервала. Дополнительно можно передать ID образца и поддерживаемые поля ЛБА, кальцита, доломита и интерпретации. Пустое значение означает отсутствие нового результата и не очищает проект. Максимальный размер одного импорта — 10 000 строк.

## Рабочий процесс

1. Откройте **Файл → Импорт поздних анализов…**.
2. Выберите файл результатов.
3. Программа сопоставит строки с существующими интервалами шлама и покажет preview.
4. Проверьте совпадения, пропуски и конфликты. Уже заполненные значения защищены от перезаписи.
5. Отметьте только те пустые поля, которые действительно нужно заполнить.
6. Подтвердите применение.

Повторный импорт тех же значений является безопасным no-op: проект не получает лишнюю ревизию и повторное сохранение не выполняется.

## Сохранение и отказоустойчивость

После подтверждения программа сначала применяет выбранный fill-only diff к текущей скважине, затем сохраняет проект штатным `MATERIAL_AUTOSAVE`. В историю `analysis_update_history` записываются источник, SHA-256 файла, выбранные поля, точный diff и контрольные hashes состояния.

Если запись проекта завершается ошибкой, изменение считается неуспешным: значения шлама, история анализов, ревизия скважины и исходное состояние `dirty` восстанавливаются. Сообщение об успешном сохранении появляется только после успешной записи проекта.

## Ограничения текущего инкремента

- Старый бинарный `.xls` не поддерживается; сохраните его как `.xlsx`.
- Для Excel используется первый лист книги.
- Эта команда обновляет только отдельные анализы существующих проб и не переносит пользовательские рисунки.
- Конфликтующие числовые коды пород разных поставщиков относятся к профилям PROJ-09 и не разрешаются этой командой автоматически.
