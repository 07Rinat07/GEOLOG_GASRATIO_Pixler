# GEOLOG GASRATIO@Pixler 0.7.83 — совместимость GeoScape WITS

Исправлена стандартная шапка GSWITS: `01` — скважина, `02` — секция/боковой ствол,
`03` — идентификатор записи, `04` — sequence, `05` — дата, `06` — время, `07` — код работы.
Sequence tracking, gaps, duplicates и provenance теперь используют item `04`.

Добавлен полный производный каталог GeoSensor WITS Level 0: 963 поля, записи 1–25, типы и mnemonic.
Каталог создаётся воспроизводимым инструментом из `GeoScape/WITS.csv`; vendor EXE/BPL/MDB/PDF в wheel
и исходный архив не включаются. Сохранены проектный формат `v20`, form schema `v8`, tablet layout
`v18`, готовый пользовательский шаблон и прежние компактные ограничения 50%, 48 и 80.
