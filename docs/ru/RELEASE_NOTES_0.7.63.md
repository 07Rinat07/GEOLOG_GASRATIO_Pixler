# 0.7.63 — компактные геологические колонки и встроенная пользовательская MASTERLOG-форма

Версия 0.7.63 освобождает больше горизонтального места на планшете, не уменьшая обычные графики
кривых и текстовые колонки. Во всех встроенных глубинных формах базовая ширина колонок
**Стратиграфия**, **Литология**, **Шламограмма**, **Кальциметрия**, **ЛБА** и **Глубина**
уменьшена на 40%. Для этих типов разрешён минимум 48 px, а для кривых и текста сохраняется
безопасный минимум 80 px.

Старые пользовательские формы и сохранённые компоновки планшета автоматически мигрируют при
открытии. Уменьшаются только перечисленные геологические колонки; ширины кривых и текста не
изменяются. После сохранения используются form schema v7 и tablet layout v17, поэтому повторного
сжатия при следующих открытиях не происходит.

Проверенная пользовательская компоновка добавлена в приложение как защищённый встроенный шаблон
**«MASTERLOG — геолого-геохимическая форма»**. Для редактирования пользователь создаёт копию,
а исходный шаблон приложения остаётся неизменным. Печать в режиме «Фактический размер» сохраняет
компактные пропорции, а режим «Автоподбор колонок» может перераспределить ширины под лист.

Инструкции RU/KK/EN синхронно описывают ширины, ручное изменение размера, миграцию, сохранение и
повторное открытие, печать и встроенный пользовательский шаблон. Регрессионные тесты проверяют
ограничения ширины, заводские формы, старые пользовательские формы, миграцию layout и MASTERLOG.

Формат проекта остаётся v20. Схема форм повышена с v6 до v7, формат планшета — с v16 до v17.
Корневой README остаётся кратким и не изменён.
