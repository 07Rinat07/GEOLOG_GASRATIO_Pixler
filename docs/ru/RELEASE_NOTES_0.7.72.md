# GEOLOG GASRATIO@Pixler 0.7.72 — панели вне native QToolBar и практически неограниченное сжатие значков

## Адаптация интерфейса

- Главная командная строка и строка **«Редактирование формы (F4)»** больше не являются `QToolBar` и не размещаются в native toolbar-area `QMainWindow`.
- Обе строки являются обычными `QFrame`-контейнерами над рабочей областью и физически ограничены шириной центральной области; системной стрелки расширения Qt в них больше нет.
- Изменение состояния кнопок, включение F4, перенос между ноутбуком и внешним монитором и смена DPI больше не могут увеличить минимальную ширину окна.
- Дополнительная защита ограничивает минимальный размер главного окна рабочей областью активного монитора.
- Правая команда **«Редактирование формы»** остаётся внутри окна; менее приоритетные команды переходят в режим значков и меню **`⋯`**.

## Значки на графике

- Практический предел сжатия значка снижен до `0,01` логического пикселя в сохраняемой геометрии; при отрисовке это соответствует минимально видимой линии в один пиксель устройства.
- Ширина и высота изменяются независимо: боковые маркеры меняют одну ось, угловые — обе; **Shift** сохраняет пропорции.
- Для очень тонкого значка используется отдельная удобная рамка выделения размером не менее `18×18 px`; она не меняет фактический размер значка и не сохраняется как его геометрия.
- Тонкий значок можно повторно выделить, растянуть и переместить после **Ctrl+S** и повторного открытия проекта.
- Обычные изображения, комментарии и выноски сохраняют безопасный минимум `40×24 px`.

## Сопутствующие исправления

- CSV/XLSX из одного `ResolvedReportDefinition` теперь корректно экспортируют активный числовой
  TIME-индекс по точному набору строк, с TIME в первом столбце и нейтральными границами интервала.
- Панель статистики интервала сохраняет достаточную область для ручного перемещения после resize.
- Удалены дублирующие UI-модули импорта; все пять источников используют единый
  `DatasetImportJobExecutor` и общий Import Review.

Project format остаётся `v20`, form schema — `v8`, tablet layout — `v18`.
