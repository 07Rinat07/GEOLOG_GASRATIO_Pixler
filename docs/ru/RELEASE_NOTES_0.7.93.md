# GEOLOG GASRATIO@Pixler 0.7.93

## Перевод форм при переключении языка

- При переключении русского, казахского или английского языка стандартные названия дорожек, разделов и параметров планшета обновляются сразу, без повторного применения формы.
- Примеры: `Бурение` → `Бұрғылау` / `Drilling`, `Описание пород` → `Тау жыныстарының сипаттамасы` / `Rock description`, `Газ C1–C5` → `C1–C5 газы` / `C1–C5 gas`.
- Числовые суффиксы автоматически разделённых колонок сохраняются: `Бурение 2` → `Drilling 2`.
- Названия технологических параметров переводятся по словарю заводских форм и каталогу Sensors.

## Породы

- Названия пород из каталога переводятся в сводке визирной линии, составе шлама и резервном тексте колонки описания пород.
- Точное каталожное название породы в описании также отображается на активном языке.
- Свободные пользовательские описания и авторские названия не переводятся автоматически и не изменяются.
