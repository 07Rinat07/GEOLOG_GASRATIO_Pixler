# Инвентарь WITSML 2.x

## Назначение

Инвентарь выполняет безопасный read-only разбор локальных WITSML 2.x данных до их импорта в
проект. Он показывает top-level объекты, версии схемы, UUID, ссылки между объектами и параметры
каналов. Операция не создаёт `Dataset`, не изменяет проект и не подключается к серверу.

Открытие: **Файл → Инвентарь WITSML 2.x…**. Поддерживается также перетаскивание файла в главное
окно.

## Поддерживаемые источники

- отдельный `.xml` или `.witsml` файл;
- каталог с рекурсивным поиском XML/WITSML;
- `.epc` или `.zip` пакет, прочитанный в памяти без извлечения файлов на диск.

Распознаются только top-level объекты с namespace WITSML 2.x. `schemaVersion` должна относиться к
ветке 2.x. Некорректный объект в смешанном пакете попадает в диагностику, а корректные объекты
остаются доступны для просмотра.

Для ручной проверки включён синтетический пример `resources/samples/witsml/channel_2_1.xml`.

## Данные объекта и канала

Для каждого объекта отображаются исходный файл, XML-тип, `schemaVersion`, название из
`Citation`, UUID/uid, `GrowingStatus` и число найденных ссылок. Для `Channel` дополнительно
показываются:

- `Mnemonic`, `DataType`, `Uom`, `Source`, `LoggingMethod` и класс канала;
- все прямые `Index` с типом, мнемоникой, единицей, направлением и datum reference;
- `StartIndex` и `EndIndex`.

Этот слой является инвентарём и preflight-проверкой. Семантическое сопоставление каналов,
создание acquisition-схемы и запись строк в `Dataset` будут отдельной атомарной операцией.

## Граница безопасности

ZIP/EPC никогда не распаковывается в файловую систему. Проверяются traversal-пути, повторяющиеся
имена без учёта регистра, шифрование, размер отдельных элементов, суммарный распакованный размер,
коэффициент сжатия и число XML-элементов. DTD и пользовательские XML entity запрещены. Для
одиночного файла и каталога действуют те же лимиты размера и числа элементов.

Предельные значения задаются через `WitsmlInventoryLimits`; значения по умолчанию рассчитаны на
офлайн-инвентаризацию, а не на неограниченную загрузку больших временных рядов.

## Текущие ограничения

- XML Schema validation по официальному набору XSD пока не выполняется;
- WITSML 1.x не поддерживается;
- channel data arrays не импортируются;
- ETP 1.2, авторизация, TLS и сетевые секреты не реализованы;
- содержимое пакета не считается доверенным только из-за расширения `.epc` или `.zip`.
