# GEOLOG GASRATIO@Pixler 0.7.71 — жёсткое ограничение панелей и реальное сужение значков

## Панели интерфейса

- Главная панель и панель **«Редактирование формы (F4)»** больше не могут увеличивать минимальную ширину окна.
- Для обеих панелей введён жёсткий предел по фактической логической ширине окна после применения DPI.
- Пересчёт выполняется сразу после показа/скрытия F4-панели, изменения состояния команд и повторно после обновления метрик Windows.
- Правая команда **«Редактирование формы»** остаётся внутри окна; второстепенные команды переходят в режим значков и меню **`⋯`**.
- Исправлен сценарий, когда после нескольких нажатий на внешнем мониторе интерфейс начинал рассчитываться шире экрана.

## Значки на графике

- Устранён скрытый общий предел `40×24 px` в экранной и печатной компоновке аннотаций.
- Значок из справочника теперь действительно можно сжимать по ширине и высоте до `1×1` логического пикселя.
- Левый/правый маркер меняет ширину, верхний/нижний — высоту, угловые маркеры — обе стороны; `Shift` сохраняет пропорции.
- Обычные изображения, комментарии и выноски сохраняют безопасный минимум `40×24 px`.
- Минимальная геометрия сохраняется в проекте и одинаково используется на экране, в preview, PDF и печати.

Project format остаётся `v20`, form schema — `v8`, tablet layout — `v18`.
