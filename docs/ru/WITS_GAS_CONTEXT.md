# Контекст газовых событий WITS / ГТИ

## Зачем это нужно

Высокий Total Gas сам по себе не доказывает наличие УВ-пласта. Интерпретатор должен различать
геологический сигнал и технологические/QC-события. Контекст газа хранится отдельно от
предварительного типа флюида по Haworth/Pixler.

## Рабочие классы

- **Фоновый газ (BGG)** — устойчивый базовый уровень при стабильном бурении в относительно
  однородном интервале. Используется как rolling baseline.
- **Пластовое газопроявление (formation show)** — устойчивое превышение robust background при
  пригодном drilling-контексте после исключения connection/trip/test/calibration событий.
- **Газ наращивания / connection gas (CG)** — краткий пик, связанный с остановкой насосов и
  наращиванием; на поверхности ожидается примерно через один лаг после connection event.
- **Газ СПО / trip gas (TG)** — газ, набранный при остановленной циркуляции и/или swab effect
  во время СПО и проявившийся после возобновления циркуляции.
- **Циркулированный/рециркулированный газ** — газ, связанный с циркуляцией или остаточным газом,
  повторно попавшим в циркуляционную систему.
- **Тест хроматографа / калибровочный газ** — сертифицированная тестовая смесь или QC-подача
  непосредственно в анализатор. Никогда не должна классифицироваться как formation show.
- **Тест газовой линии ГТИ** — газ, поданный для проверки sample line/trap-to-unit path.
  Также исключается из геологической интерпретации.
- **Lag tracer / carbide test** — искусственно введённый трассер для проверки lag.
- **Elevated-unclassified** — газ повышен, но данных для надёжного происхождения недостаточно.

## Автоматика + ручное подтверждение

Рекомендуется гибридная схема.

Автоматика предлагает контекст из WITS-параметров: насосы/SPM/flow, ROP, bit depth,
block position, on-bottom/off-bottom, drilling activity, connection/trip events и lag model.
Но оператор может создать **ручной подтверждённый интервал** с:

- типом события;
- осью: глубина или elapsed time;
- началом и концом;
- optional значением и единицей;
- комментарием;
- признаком confirmed.

Ручные QC/test-интервалы имеют приоритет над автоматическим formation show. В пересечении
«пластовый газ» + «тест хроматографа» отчёт должен считать интервал тестовым, а не пластовым.

## Lag / привязка к глубине

Surface gas приходит позже события на долоте. Поэтому отчёт должен хранить отдельно:

1. время/глубину регистрации на поверхности;
2. lag/cycle estimate;
3. lag-corrected bit depth;
4. источник lag: расчётный, connection-gas marker, tracer/carbide test или ручная коррекция.

Без валидного lag приложение не должно уверенно присваивать поверхностный газ конкретному
разбуриваемому пласту.
