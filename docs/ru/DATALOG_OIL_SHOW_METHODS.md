# Нефтепроявления DataLog / MOL — работа с наблюдениями

**Статус:** справочник и программная проверка полноты записей разрабатываются в отдельном PR; **нового экрана DataLog пока нет**. Используйте существующий редактор шлама/ЛБА без изменения старых LAS и проектов.

По предоставленной таблице «Нефтепроявления_оценки.xls» фиксируйте разные наблюдения, не объединяя их в один «балл нефти»:

1. **Запах и видимые пятна** в обычном свете: характер, распространение, цвет, расположение в порах или трещинах.
2. **Прямая флуоресценция (DIF, UV+)** до внесения реагента: доля материала (по целевой литологии), распределение, интенсивность, цвет.
3. **Растворительная проба (cut):** отдельно скорость и характер проявления, цвет при обычном освещении (UV−) и цвет/интенсивность в УФ (UV+).
4. **Остаток после cut:** тип и цвет в обычном освещении и отдельно тип/цвет свечения остатка в УФ.
5. **ЛБА Флоровской:** отдельно группа битумоида, цвет и балл 1–5 по люминесцирующему пятну капиллярной вытяжки на бумаге. Это **не** остаток cut на фарфоровой пластинке.

Сейчас карточка пробы имеет общие поля `lba_cut_*`, `lba_residue_*` и не сохраняет полный набор отдельных UV−/UV+ измерений, площади и яркости для каждого метода. Не угадывайте пропущенные значения; оставляйте их неизвестными. В свободном описании до расширения схемы можно явно указать метод и освещение, но это **не делает текст структурированным измерением**.

Контролируйте чистоту тарелки, фон растворителя и бурового раствора, загрязнение смазкой/реагентами, наличие углей и минералов, влияние промывки, временную задержку и лаг глубины. Результат DataLog не является доказательством нефтяного пласта без ГИС и испытаний.

**Безопасность:** никакой проверки H₂S по запаху. Используйте предусмотренные промышленной безопасностью приборы и процедуры. Ацетон **смешивается с водой**; неверное обратное утверждение из загруженного справочника не является рабочей инструкцией. Работа с растворителями — только по утверждённой процедуре и паспорту безопасности вещества.
