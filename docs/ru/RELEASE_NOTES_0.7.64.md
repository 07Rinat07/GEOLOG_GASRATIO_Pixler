# 0.7.64 — справочник названий при создании формы

Команда **«Создать форму»** теперь открывает отдельное окно со всеми встроенными и
пользовательскими формами. В нём доступны поиск, название, тип оси и источник. При выборе формы
справа показываются описание, видимые колонки и их сохранённая ширина, количество дорожек и
параметров, а также мнемоники привязанных кривых.

Новое название вводится в том же окне вместе с выбором оси **«Глубина»** или **«Время»**.
Случайные пробелы удаляются, повторяющиеся внутренние пробелы объединяются. Полное совпадение с
существующим названием блокируется без учёта регистра и лишних пробелов.

Существующий набор защищённых шаблонов сохранён без отдельного дублирующего шаблона MASTERLOG. Сохраняются компактные ширины 0.7.63:
стратиграфия, литология, шламограмма, кальциметрия, ЛБА и глубина уменьшены на 40% и допускают
минимум 48 px; обычные графики и текст сохраняют минимум 80 px.

Документация, инструкции, статус, план и тесты обновлены на русском, казахском и английском.
Project format остаётся v20, form schema — v7, tablet layout — v17.
