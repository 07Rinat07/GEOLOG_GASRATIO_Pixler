# Сохранение импортированных и изменённых данных

## Информационная панель текущей сессии

В нижней строке приложения постоянно показываются проект, скважина, активный набор данных,
исходный файл и состояние **Сохранено / Изменено**. Подробная подсказка панели содержит полный
путь источника, формат, число строк и кривых, путь проекта и предполагаемый вариант сохранения.

## Закрытие программы

Если в рабочей сессии есть несохранённые изменения, при закрытии предлагаются четыре действия:

1. **Сохранить проект** — сохраняет данные, формы, оформление, интервалы и остальные проектные
   объекты в основном формате `*.geologpkg`; открытый старый `*.geolog.json` повторно сохраняется
   для совместимости.
2. **Экспортировать LAS-копию** — сохраняет текущие числовые кривые и заголовки в новый LAS.
3. **Не сохранять** — закрывает программу с потерей изменений текущей сессии.
4. **Отмена** — возвращает в программу.

Исходные GeoScape, GeoScape II/GS2 и Paradox-файлы автоматически не перезаписываются: для них
используйте проект или новый LAS. При работе с исходным LAS программа также всегда открывает
диалог выбора имени и места; по умолчанию предлагается имя вида `original_edited.las`.

## Где находится сохранённый файл

После успешного сохранения проекта или LAS приложение показывает полный путь и предлагает открыть
папку с файлом. Первое сохранение проекта и команда **Сохранить как…** всегда запрашивают папку и
имя. Обычный **Ctrl+S** повторно записывает уже выбранный файл проекта.

Экспорт LAS не заменяет сохранение проекта: LAS не хранит формы, оформление, изображения,
шламограмму, ЛБА, интервалы интерпретации и другие проектные слои.
