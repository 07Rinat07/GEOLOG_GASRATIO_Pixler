# Сохранение импортированных и изменённых данных

## Информационная панель текущей сессии

В нижней строке приложения постоянно показана цепочка **Источник → Файл проекта → Экспорт**,
а также скважина, активный набор данных и состояние **Сохранено / Изменено**. Источник остаётся
read-only. До первого сохранения поле проекта показывает **«не сохранён»**, после него — полный
путь активного `.geologpkg`. Поле экспорта поясняет, что LAS создаётся отдельной копией.
Подробная подсказка содержит полный путь источника, формат, число строк и кривых.

## «Сохранить LAS» после Paradox и GS2

При прямом импорте Paradox DB или GS2 действие **«Сохранить LAS»** открывает единый штатный
экспорт только после успешной проверки и регистрации Dataset. Отмена Import Review, закрытие
диалога или ошибка не запускает экспорт и не создаёт частичный файл. **Ctrl+S** при этом сохраняет
весь проект, а не LAS-копию.

## Закрытие программы

Если в рабочей сессии есть несохранённые изменения, действующая защита при закрытии предлагает
четыре действия:

1. **Сохранить проект** — сохраняет данные, формы, оформление, интервалы и остальные проектные
   объекты в основном формате `*.geologpkg`; открытый старый `*.geolog.json` повторно сохраняется
   для совместимости.
2. **Экспортировать LAS-копию** — сохраняет текущие числовые кривые и заголовки в новый LAS.
3. **Не сохранять** — закрывает программу с потерей изменений текущей сессии.
4. **Отмена** — возвращает в программу.

Ежедневное наращивание является отдельной защищённой материальной операцией: до изменения нужен
рабочий `.geologpkg`, после успешного append новая ревизия сохраняется автоматически, а прежняя
попадает в `.geolog-backups`. Повторный identical LAS ничего не сохраняет. Обычный ручной ввод
по-прежнему сохраняйте через **Ctrl+S**.

Если синхронизация изменила проект после открытия, перезапись блокируется. Сохраните текущую
сессию под новым именем либо откройте актуальный файл. Проверенную прежнюю ревизию можно вернуть
командой **Файл → Восстановить recovery-копию...** только в новый `.geologpkg`; активный файл
эта команда не перезаписывает.

Исходные GeoScape, GeoScape II/GS2 и Paradox-файлы автоматически не перезаписываются: для них
используйте проект или новый LAS. При работе с исходным LAS программа также всегда открывает
диалог выбора имени и места; по умолчанию предлагается имя вида `original_edited.las`.

## Где находится сохранённый файл

После успешного сохранения проекта или LAS приложение показывает полный путь и предлагает открыть
папку с файлом. Первое сохранение проекта и команда **Сохранить как…** всегда запрашивают папку и
имя. Обычный **Ctrl+S** повторно записывает уже выбранный файл проекта.

Экспорт LAS не заменяет сохранение проекта: LAS не хранит формы, оформление, изображения,
шламограмму, ЛБА, интервалы интерпретации и другие проектные слои.
