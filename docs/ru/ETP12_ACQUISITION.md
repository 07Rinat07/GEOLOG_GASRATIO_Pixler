# Запись ETP 1.2 ChannelData

Версия 0.7.82 преобразует подтверждённые ETP ChannelData в неизменяемые нормализованные пакеты и
append-only записи AcquisitionSession.

## Устойчивая идентичность

Числовые ID каналов ETP действуют только в пределах согласованной сессии и после reconnect могут
измениться. Поэтому mapping, семантическая идентичность и дедупликация используют URI канала. Каждый
пакет содержит актуальное соответствие `channel_id -> URI` и generation подписки.

## Import Review

`Etp12DiscoveryAccumulator` объединяет ChannelMetadata и статистику принятых значений. Fingerprint не
зависит от временных channel ID, generation и счётчиков выборки. Import Review подтверждает числовые
каналы, семантику, канонические мнемоники, физические величины, индекс и преобразования UOM. Commit
создаёт immutable `AcquisitionDatasetSchema`.

## Нормализация

`Etp12ChannelNormalizer` группирует точки по каноническому индексу, переводит ETP-время из микросекунд
в Unix nanoseconds и выполняет только явно поддерживаемые преобразования единиц. Каждая строка
содержит точный набор curves схемы; отсутствующие значения сохраняются как null/NaN.

## Перекрытие после reconnect

Для принятой точки вычисляется SHA-256 по digest схемы, URI канала, нормализованному индексу и значению.
Ограниченное окно дедупликации удаляет точное перекрытие после восстановления подписки даже при новых
числовых ID. Изменившееся значение на том же индексе остаётся новой append-only записью. Point hashes
сохраняются в provenance AcquisitionRecord и восстанавливаются после повторного открытия проекта.

## Runtime

`Etp12AcquisitionRuntime` обеспечивает bounded queue, атомарную постановку нескольких строк,
backpressure, checkpoints, controlled close и возобновление открытой сессии. Формат проекта остаётся v20.
