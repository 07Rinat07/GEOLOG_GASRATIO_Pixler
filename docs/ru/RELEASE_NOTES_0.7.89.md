# GEOLOG GASRATIO@Pixler 0.7.89

Исправлено применение и восстановление форм после открытия нового набора GeoScape2 GS2.
Сохранённый формой идентификатор вертикальной оси теперь проверяется относительно
текущего dataset. Устаревшая ссылка заменяется активной осью без ошибки
`NoneType.role`. Для абсолютного времени относительная TIME-ось переводится в
DATETIME, а явно выбранная глубина сохраняется.

Формат проекта остаётся v21, схема формы — v9, layout планшета — v19. Существующие
заводские и пользовательские формы совместимы без преобразования.
