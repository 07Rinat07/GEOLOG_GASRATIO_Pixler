# GEOLOG GASRATIO@Pixler 0.7.92

## Компактные подписи колонок планшета

- Длинные подписи **Стратиграфия** и **Шламограмма** теперь выводятся одной строкой под 90° и автоматически уменьшаются ровно настолько, чтобы полностью поместиться без обрезания.
- Высота полосы повёрнутого заголовка увеличена с 88 до 96 px для стабильного отображения при разных шрифтах и DPI Windows.
- Подпись **ЛБА** во всех готовых и пользовательских формах по умолчанию горизонтальная: для трёх букв поворот не нужен.
- Глубина/Время, Стратиграфия, Литология, Шламограмма и Кальциметрия сохраняют вертикальный компактный режим.

## Совместимость форм

- Project format: `v21`.
- Form schema: `v11`.
- Tablet layout: `v21`.
- Старые form v8 и tablet v18, а также формы 0.7.91, мигрируются автоматически.
- Компактные колонки сохраняют уменьшение ширины на 50% с минимумом 48 px; обычные кривые сохраняют минимум 80 px.

## Рабочий процесс форм

Команды **Создать форму** и **Сохранить пользовательскую форму** остаются без изменений. Библиотека показывает все готовые и пользовательские формы; совпадение имени проверяется без учёта регистра и лишних пробелов.

Канонический запуск: `python -m geoworkbench.app.main`.
