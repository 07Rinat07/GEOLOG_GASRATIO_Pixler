# Импорт GeoScape II GS2

## Текущий контракт

`.gs2` рассматривается как неизменяемый ZIP-контейнер GeoScape II, а не как отдельная таблица
Paradox. Импортёр:

- проверяет ZIP-сигнатуру независимо от расширения;
- требует один `GS2.mdb` и хотя бы одну таблицу `GS2#*.db`;
- отклоняет traversal-пути, дубли имён без учёта регистра, шифрование, превышение количества,
  размера и коэффициента сжатия;
- извлекает только выбранные элементы во временный автоматически удаляемый каталог;
- показывает таблицы, число строк/полей и роли TIME/DEPTH до импорта;
- передаёт выбранную Paradox-таблицу через mapping и Import Review;
- сохраняет source fingerprint, выбранный member и metadata evidence в provenance `Dataset`.

Расширение само по себе не делает контейнер доверенным. Исходный `.gs2` не изменяется.

## Multipart-таблицы

Части предлагаются как одна серия, только если присутствуют базовый member и все последовательные
суффиксы, совпадают имена/типы/размеры полей и существует TIME-индекс. Валидные фрагменты группы
скрываются из обычного списка, чтобы оператор не импортировал случайную неполную серию.

Перед объединением время нормализуется в секунды. Импортёр отклоняет немонотонные части и
перекрытия, сообщает о крупных разрывах, проверяет memory budget, один раз выделяет итоговые
массивы и поддерживает progress/cancel на чтении и объединении.

## Metadata Access

`GS2.mdb` открывается только из временной копии через заменяемый read-only adapter. Windows
реализация использует Qt SQL ODBC и требует Microsoft Access Database Engine той же разрядности,
что приложение. Отсутствующий QODBC/ACE, несовпадение разрядности или ошибка открытия дают
понятную диагностику, но не блокируют корректную Paradox-таблицу.

Проекция читает `WELLS`, `FORMULAS`, `LOGGINGSERVICE`, распознанные channel-like таблицы и список
таблиц. Применяется только явная связь metadata с source channel; неизвестные `Sxxx`/`SBxxxx`
сохраняются без догадок. Формулы без идентификатора результата не связываются автоматически.
Well passport, formula snapshot, channel relations и driver diagnostics сохраняются в
`Dataset.parameters`.

Новая схема Access добавляется отдельной projection-реализацией, без изменения ZIP/Paradox
reader.

## Индекс и ресемплинг

Импорт сохраняет исходные значения и фактический TIME/DEPTH-индекс. Номинальный шаг оценивается
устойчиво к единичным разрывам. Перевод на сетку проекта является отдельной производной операцией
и не изменяет исходный `Dataset`.

## Критерий готовности

Поддержка считается полевой только после проверки минимум трёх обезличенных версий контейнера и
сравнения TIME/DEPTH, C1–C5, total gas, UOM, Gas Ratio и Pixler с авторитетным LAS/Excel export.
Regression fixtures должны быть синтетическими или обезличенными и покрывать multipart, NULL,
отмену, повреждение, cleanup и memory limits.
