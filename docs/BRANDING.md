# Брендинг приложения

Каноническое отображаемое название продукта: **DIGITAL GEOLOG GASRATIO&PIXLER**. Оно используется в окнах приложения, splash screen, окне «О программе», документации и печатных/экспортных отчётах. Значение хранится централизованно в `src/geoworkbench/brand.py`.

Основной UI-логотип хранится в `src/geoworkbench/resources/digital-geolog-logo.svg`.
Для печатного каталога тот же предоставленный владельцем растр хранится отдельно как
`src/geoworkbench/resources/digital-geolog-logo.jpg` и при установке заводского логотипа
нормализуется в PNG через общий image-asset boundary. Это сохраняет строгую SVG-валидацию
проектных assets: embedded `<image href="data:...">` не разрешается как сохраняемый SVG.

Ресурсы загружаются через `importlib.resources`, поэтому работают из исходного дерева и после
установки wheel. `pyproject.toml` явно включает `resources/*.png`, `resources/*.jpg` и
`resources/*.svg` в package data. Изображения предоставлены владельцем проекта и
распространяются вместе с приложением на условиях Proprietary License проекта.

Логотип используется как единый канонический ресурс бренда:

- как иконка `QApplication` и главного окна;
- на главной странице приложения;
- в splash screen;
- в диалоге «О программе»;
- в README и других брендовых представлениях;
- как заводской логотип в печатных шапках и экспорте Masterlog.

Главная страница дополнительно использует предоставленную владельцем иллюстрацию
`src/geoworkbench/resources/home-geology-background.svg` только как декоративный фон
в свободном левом поле на широких экранах. Она скрывается при недостатке места и не
перекрывает рабочие карточки, меню или панели.

Отдельного изображения для окна «О программе» нет: все поверхности приложения используют
один и тот же `digital-geolog-logo.svg`, чтобы старый логотип не мог случайно вернуться.

UI-логотип и фоновая иллюстрация остаются SVG-контейнерами для экранного рендеринга.
Печатный каталог использует отдельный JPEG source того же изображения и детерминированно
нормализует его в PNG перед content-addressed persistence; визуальное содержимое при этом
не перерисовывается.
