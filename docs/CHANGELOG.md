# История изменений

Здесь фиксируются только крупные продуктовые изменения. Подробная история отдельных исправлений
доступна в Git; отдельные release notes, build manifests и AI-отчёты не создаются.

## Unreleased

- При близких голосах нефтяной и газовой групп ОПУС Газомер отчёт больше не выдаёт
  безусловно один тип флюида: показывает альтернативу «нефть или горючий газ», а при
  поддержке ниже 75% — «возможно, нефть или горючий газ». Точный класс, голоса формул и
  исходные показатели сохраняются в таблице для проверки.
- Устранено повторяющееся падение Windows quality gate на GitHub: вычисление допуска
  регулярного окна ОПУС теперь явно приводит машинную точность NumPy к встроенному `float`,
  поэтому `mypy 1.19.1` из release workflow больше не выводит ошибку сложения несовместимых
  типов. Проверка не отключена и её строгость не снижена.
- Профиль «ОПУС Газомер» обновлён до `1.1.0` и стал первичным источником подписи каждого
  интервала: в заголовке показывается точный класс 1–6 по пяти формулам и голосам книги,
  Haworth/Pixler остаётся только отдельным сравнением. Измеренный ноль компонента теперь
  участвует в формулах как число; деление на ноль блокирует только затронутый показатель,
  поэтому остальные валидные голоса могут дать класс. При классе 7 отчёт показывает точную
  причину и распределение голосов, а не размытый резерв. Если TotalGas отсутствует или
  разрешён неоднозначно, применяется запрошенная синхронная сумма C1–C5 с явной подписью
  `Σ(C1–C5)` и предупреждением. На контрольном проекте исправление дало прямой результат для
  всех 64 интервалов: 63 — класс 3 «Горючий газ», один — класс 2 «Нефть».
- Для узкой колонки ЛБА добавлена отдельная настройка направления подписей «Цвет / Битум»:
  горизонтально, вертикально снизу вверх или вертикально сверху вниз. Вертикальное направление
  используется по умолчанию, балл остаётся горизонтальным, выбранный вариант сохраняется в
  проекте и восстанавливается при следующем открытии. Настройка включена во все заводские
  формы с ЛБА, переносится между планшетом и пользовательской формой и сохраняется в form
  schema v15; формы v1–v14 мигрируют к вертикальному направлению снизу вверх.
- Отчёт «Интерпретация кальциметрии и ЛБА» расширен до полного геологического отчёта:
  добавлены производная метровая таблица пород с фактическим покрытием отбора, состав и
  описание каждой пробы шлама, стратиграфия по пробам и по всей скважине, полная кальциметрия
  и все поля ЛБА. Для каждого фактического интервала выводятся минимум, среднее и максимум
  отдельной кривой `Total Gas`, всех найденных компонентов и отдельной суммы компонентов.
  Отсутствующий `Total Gas` не подменяется: сумма всё равно рассчитывается независимо по
  доступным компонентам.
- Предпросмотр полного геологического отчёта получил независимую вертикальную и горизонтальную
  прокрутку с постоянно видимыми полосами: длинный разрез можно просматривать по всем
  интервалам, а широкие таблицы — без сжатия столбцов и потери содержимого. Из газовой строки
  убрано служебное количество отсчётов — остаются только минимум, среднее и максимум.
  Экспортируемый PDF не изменяет ширину из-за настроек окна.
- Исправлена читаемость окна «Интерпретация кальциметрии и ЛБА» в тёмной теме: canvas
  предварительного просмотра, HTML-страница, заголовки и ячейки теперь явно используют белый
  фон и тёмный текст, поэтому системная тёмно-серая палитра больше не перекрывает содержимое.
- Завершены `OPUS-06/07`: regression matrix теперь проверяет совпадение готового Gasomer
  snapshot в HTML, XLSX, DOCX, PDF и print HTML вместе с формулами, классом, пятью голосами,
  QC, provenance и явной errata `AB2>AB5=250000` → `AB2>=250000`. Gasomer HTML разбит на
  пагинируемые блоки, поэтому provenance/errata/QC больше не обрезаются на границе PDF-страницы.
  Для регулярной depth-оси detector получил bounded chunked rolling
  median/MAD fast path, нерегулярная ось сохраняет physical-window fallback. Benchmark
  25k/100k/1M подтвердил близкое к линейному масштабирование: на 1M строк batch занял 0,381 с,
  detector 8,168 с, additional traced peak — 185/119 MiB. Export/print по-прежнему не
  пересчитывают формулы. До production-калибровки остаётся полевая задача `OPUS-08`.
- Завершён `OPUS-05`: immutable report snapshot теперь хранит профиль/статус, точные пять
  формул, source curves и units, явный LOD независимого TotalGas, detector evidence, прямой
  класс и support интервала, пять медианных значений/голосов, valid rows, QC distributions и
  SHA-256/provenance книги. UI принимает LOD в исходной единице TotalGas; ноль означает
  «не задан», поэтому detector не получает скрытый порог. HTML и общий PDF/print path, XLSX и
  DOCX отображают один готовый snapshot без повторного расчёта; исторический ОПУС и независимый
  Haworth/Pixler остаются отдельными результатами.
- Завершён `OPUS-04`: versioned detector выделяет проявления по локальному robust-фону
  TotalGas, `ΔTG`, robust z-score и контрасту с обязательным приборным LOD-floor. Параметры
  помечены как engineering defaults до полевой калибровки. Порог `0,1 % об.` не является hard
  gate: контрастное событие на фоне `0,0001 %` сохраняется с warning, ровный низкий фон не даёт
  ложного интервала, а смена фона по стволу не скрывает последующий пик. ppm/% и прямой/обратный
  порядок глубин дают одинаковый результат; missing/invalid TotalGas не маскируются.
- Завершён `OPUS-03`: интервал агрегирует только уникальные классы синхронных строк, сохраняя
  support, распределения классов/голосов, число валидных строк и QC каждого показателя; ничья
  остаётся неопределённой. Workbook-compatible независимые MAX вынесены в отдельный режим с
  обязательным maximum span, compatibility marker и глубиной происхождения каждого максимума.
  Тест доказывает и явно предупреждает, когда legacy MAX создаёт состав, отсутствующий на любой
  реальной глубине. Никакой глобальный MAX по всей скважине в основной расчёт не добавлен.
- Завершён расчётный этап `OPUS-02`: добавлено чистое vectorized-ядро профиля `OPUS Gasomer`
  по синхронным C1–C5 и независимому TotalGas. Поддержаны точное ppm↔`% об.`, пять показателей,
  data-driven палетки, уникальная мода без случайного разрешения ничьей и раздельные QC states
  для пропуска, измеренного нуля, below LOD и некорректного значения. Значение на LOD доступно,
  отсутствие LOD даёт warning, source arrays не изменяются. Старый ОПУС и Gas Ratio остались
  численно неизменными; detector, интервалы и пользовательский отчёт будут подключены отдельно.
- Завершён `OPUS-01`: первичная книга `Газомер.xls` прочитана только для чтения и сверена по
  SHA-256; пять формул, все границы `Y4:AC4`, контрольная строка и `MODE(Y4:AC4)` перенесены в
  versioned JSON-профиль и неизменяемый golden fixture. Добавлено чистое scalar-ядро и проверки
  каждой границы ниже/на/выше. Ошибка `AB2>AB5=250000` оформлена как явная errata и исправлена
  на включительное `AB2>=250000`. Интернет-фактчекинг разделил происхождение формул:
  `OPUS_GM_1/2` имеют открытую проверку, `GM_3/4` — вторичную, `GM_5` остаётся
  workbook-derived. Whole-well runtime и пользовательский отчёт пока не подключены.
- Создан утверждённый инженерный контракт
  [OPUS_GASOMER_IMPLEMENTATION.md](OPUS_GASOMER_IMPLEMENTATION.md) для будущего отдельного
  профиля **«ОПУС Газомер»**. В нём зафиксированы транскрипция пяти формул предоставленной
  книги, отличие нормализации на независимый TotalGas от исторического ОПУС, запрет глобальных
  независимых MAX по многокилометровому LAS, построчный/интервальный алгоритм, LOD, явная ничья
  голосов, локальный адаптивный фон и решение не использовать `0,1 % об.` как hard gate.
  Единый план дополнен задачами `OPUS-01…08`; архитектура, требования, формулы, тестовая матрица,
  навигация и каталоги источников синхронизированы. Изменение документирует будущую реализацию и
  не меняет работающие Gas Ratio/Haworth/Pixler и текущий исторический профиль ОПУС.
- Обновлено окно **«Справка → О программе»**: установлен новый встроенный логотип
  GEOLOG_GASRATIO_Pixler, добавлен презентационный обзор назначения продукта и полная
  RU/KK/EN-локализация версии, описания и контактного блока.
- Добавлен отдельный, не изменяющий стандартный расчет, вариант отчёта ОПУС с
  безопасным приведением исходных ppm/% к рабочим `% об.`. Четыре фактчекингом
  подтвержденные скрининговые кривые по
  относительному составу C1-C5: `OPUS3`, `OPUS4`, `OPUS_K1_3`, `OPUS_1_5`.
  Они рассчитываются на всей глубинной сетке только по команде «Рассчитать ОПУС».
  В PDF/DOCX/XLSX добавлен паспорт методики с формулами, единицами, правилом
  интерпретации, источником и степенью его подтверждения. Предварительная подпись
  флюида выдаётся только при единственном пересечении опубликованных диапазонов по
  отсчётам выше порога аномалии; иначе автоматически выводится явно помеченный
  резерв Haworth/Pixler или неопределённый тип.
  `OPUS5_REF` и принудительное голосование Integration Kit не выполняются без
  независимого TotalGas и доменной валидации. Исправлена потеря всех
  найденных интервалов при нулевой медиане по скважине: ограничения фона и контраста
  теперь квалифицируют применимость ОПУС, но не удаляют газовые аномалии. Графики
  дополнительного PDF теперь показывают `OPUS_TG_PCT` и показатели ОПУС, а не только
  стандартный `TG_CALC`. Для каждого выделенного интервала добавлена консервативная
  подпись «газ», «нефть», «газоконденсатная/газонефтяная залежь» или
  «окисленная/остаточная нефть»; неоднозначные пересечения так и помечаются.
  Haworth/Pixler сохранён как независимая проверка. В источниках отдельно отмечено,
  что `OPUS3/OPUS4` имеют открытую сверку формул, а `OPUS_K1_3/OPUS_1_5` и диапазоны
  — проверяемую вторичную; ОПУС не выдаётся за ГОСТ/ISO-стандарт.
- Полностью проверена локализация всех 19 встроенных планшетных форм, десяти готовых A4
  Masterlog-форм и десяти парных шапок. В RU/KK/EN теперь переключаются названия форм, колонок,
  параметров,
  газовых шкал и служебных полей печатной шапки; устранены английские подписи параметров в
  русских и казахских A4-формах и русские заголовки в английской печати. Международные
  мнемоники, химические формулы и единицы измерения сохранены без перевода. Пользовательская
  копия готовой Masterlog-формы создаётся сразу на выбранном языке. Существующая русская
  подпись «Абсолютные газы C1–C5» теперь также переводится на лету как
  «C1–C5 абсолюттік газдары» / «Absolute gas C1–C5» без пересоздания формы. Тот же runtime-
  механизм теперь использует полный каталог видимых A4-форм: составные заголовки, группы,
  параметры и газовые подписи глубинных/временных, книжных/альбомных форм переводятся сразу
  после смены языка; произвольные пользовательские названия не изменяются.
- В заводской форме **MASTERLOG — A4, альбомная** системная колонка `INTERPRETATION`
  отображается как «Описание пород». В **MASTERLOG — A4, книжная** добавлена такая же колонка;
  остальные колонки сжаты до проверенных безопасных ширин, и вся форма занимает `714 px` при
  доступных `718 px`, поэтому помещается на книжный A4 без скрытого масштабирования. Для
  четырёхзначных отметок глубинная колонка расширена до `64 px` за счёт газовой колонки `144 px`.
- Универсальный импорт сокращён до одного выбора файла: LAS, CSV/TXT, Excel, Paradox DB и GS2
  определяются по расширению. Обычный LAS использует совместимый режим, а строгая и ручная
  политики сохранены в отдельной команде расширенного импорта. Import Review стал компактным:
  итог и каналы видны сразу; индекс/NULL, ручное сопоставление, технические столбцы и подробные
  предупреждения раскрываются по запросу, а критические ошибки автоматически открывают детали.
- Колонка системного типа `INTERPRETATION` теперь показывает сохранённые описания пород на
  планшете и в Masterlog/PDF/печати, сохраняя пользовательское отображаемое название. В режиме
  выбора `Shift + левая кнопка` создаёт произвольный интервал описания, после чего можно точно
  исправить кровлю и подошву, выбрать готовый шаблон RU/KZ/EN либо ввести свободный rich text.
  Двойной щелчок повторно открывает описание. Удаление описания не удаляет состав пробы, ЛБА и
  кальциметрию; существующие интервалы интерпретации сохраняются. Для коротких интервалов
  добавлены автоматический перенос слов, уменьшение шрифта, безопасное сокращение с многоточием
  и выравнивание слева/по центру/справа. Экранный и печатный текст ограничен границами интервала;
  после увеличения масштаба полный экранный текст восстанавливается автоматически. Изменение
  ширины колонки теперь запускает повторную адаптацию по фактической ширине viewport. Добавлен
  сохраняемый флажок переноса слов, включённый по умолчанию; без переноса строка уменьшается и
  безопасно сокращается по ширине.
- Устранено накопление скрытых PDF при предпросмотре и физической печати: эти режимы теперь
  рендерят документ напрямую и не создают бессрочную копию при каждом `paintRequested`.
  При запуске безопасно удаляются старые timestamp-копии и их аварийные `.tmp` только из
  выделенного каталога приложения; каталог с посторонними файлами не принимается во владение.
  Новые атомарные export-времянки имеют явный префикс `geolog-export-`, а остатки старше суток
  удаляются перед повторным экспортом того же итогового файла.
- Проверен архив GeoScape2: встроенный каталог покрывает все 317 `GID` из `Sensors.DB`, включая
  `iC4/nC4/iC5/nC5`. Добавлены контролируемые международные варианты изомерных, ROP- и
  bit-size-мнемоник.
- Эквивалентные числовые дубли после объединения LAS больше не создают ложную неоднозначность;
  реально отличающиеся каналы по-прежнему требуют выбора оператора.
- По руководству GeoScape II подтверждён семикомпонентный выход хроматографа. Старые
  `C4/C5` рядом с `iC4/iC5` теперь распознаются как контекстные алиасы `nC4/nC5` без
  вычитания, изменения source-кривых или выдуманных значений; явные total-каналы и идентичные
  iso-дубли остаются неподставленными. Канонический семикомпонентный набор и состав базового
  mud log дополнительно сверены с официальными материалами Schlumberger/SLB.
- Комплексная газовая A4-форма приведена к отраслевому порядку integrated gas log:
  `Depth/ROP → C1–C5 → Total Gas → normalized C1–C5 → relative composition →
  Wetness/Balance/Character и изомеры → Pixler`. Полные `iC4/nC4/iC5/nC5` сохраняются,
  если присутствуют в источнике; единицы исходных ROP и газовых каналов не подменяются.
- Повторная шапка колонок теперь всегда печатается на отдельной финальной странице, а не внутри
  последней страницы планшета. Поэтому ограничение по высоте больше не уменьшает её ширину:
  шапка использует тот же масштаб по ширине, что и график. Все семь строк C1–nC5 входят в обе
  шапки; проверка выполнена на реальном LAS, GS2 time, BLData, старой DB и synthetic
  seven-component regression.
- Off-scale значения больше не превращаются в `NaN`-острова: непрерывный сегмент проходит через
  ограниченную off-screen область и обрезается viewport/PDF, а реальные `NaN` и недопустимые
  logarithmic values остаются разрывами. Экстремальные выбросы ограничены безопасным overscan.
- Экран интерпретации получил явный сценарий `1. входы → 2. расчёт → 3. проверка →
  4. печать/экспорт`; шаг 4 открывает готовый отчёт и переводит фокус к печатным действиям.
- Объединены calculation и render continuity rules: C1–C5 и производные газовые кривые кондиционируются на полном общем depth basis, короткие sparse updates образуют линии через явный segment mask, а длинные остановки и реальные нули сохраняются как разрывы.
- Добавлен общий Qt-независимый контракт вертикальной шкалы, tablet layout v22 и form schema v14: общий шаг задаётся один раз, а каждая графическая колонка может выбрать автоматический режим, цифры и риски, только риски или отключение и настроить частоту. Настройка доступна и в редакторе живой колонки, и в редакторе структуры формы на RU/KK/EN, сохраняется в пользовательском шаблоне и переносится на экран/PDF; колонка не может создать собственные значения глубины или Y-координаты. Формы v1–v13 мигрируют к безопасному видимому автоматическому режиму.
- Введён Qt-независимый контур conditioning газовых данных: C1–C5 обрабатываются на неизменяемой
  рабочей копии до расчёта `TG_CALC`, относительных компонентов, Haworth, изомерных отношений и
