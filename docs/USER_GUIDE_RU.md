# Руководство пользователя GEOLOG GASRATIO@Pixler

## 1. Порядок разделов

Интерфейс организован по назначению:

- **рабочие вкладки** — кривые, таблица LAS и планшет;
- **Инструменты** — окно «Файлы / PDF / Калькулятор»;
- **Печать** — центр печати и отчёты по интерпретации;
- **Справка** — документация, инструкции, журналы и диагностический пакет.

Служебные окна открываются отдельно и больше не занимают постоянные вкладки.

## 2. Файлы, PDF и калькуляторы

Откройте **Инструменты → Файлы / PDF / Калькулятор**.

1. Выберите поддерживаемый файл и дождитесь полной загрузки.
2. Перед редактированием PDF проверьте страницу и масштаб.
3. Пока исходник нужен, сохраняйте результат под новым именем.
4. В калькуляторах обязательно проверяйте единицы входных данных.
5. Не используйте результат при пустых, отрицательных или физически невозможных значениях.
6. Если PyMuPDF или Pillow не установлены, основное приложение продолжит работу, а окно покажет команду установки.

## 3. Центр печати

Откройте **Печать → Центр печати**.

1. Проверьте скважину, dataset и выбранный интервал.
2. Выберите бумагу, ориентацию, поля, масштаб и шапку.
3. Для широких графиков используйте альбомную ориентацию A4 или A3.
4. Откройте предпросмотр и проверьте все страницы.
5. Убедитесь, что графики не разрезаны, подписи читаемы, а правая шкала находится внутри печатной области.
6. Сначала сохраните контрольный PDF. Физическую печать выполняйте только после его просмотра.

Успешное завершение экспорта не гарантирует правильную компоновку. Итоговый файл необходимо открыть и проверить.

## 4. Отчёты по интерпретации

Откройте **Печать → Отчёты по интерпретации**.

Доступны:

- **Интерпретация газового каротажа** — расчёты, графики, перспективные интервалы, Excel, Word, PDF и печать;
- **Кальциметрия и LBA** — отдельный интерпретационный отчёт.

### Порядок подготовки отчёта газового каротажа

1. Выберите скважину и набор данных.
2. Проверьте C1–C5, ROP, RPM, WOB, BIT/BS и FLOW.
3. Выберите источник нормализованного газа.
4. Настройте BIT, ROP_REF, BIT_REF, FLOW_REF и эффективность газовой системы.
5. Пересчитайте доступные кривые.
6. Проверьте качество DEXP и причины разрывов.
7. Обновите отчёт с графиками.
8. Проверьте шкалы, единицы, абсолютные C1–C5 и перспективные интервалы.
9. Сохраните Excel или Word для контроля таблиц.
10. Создайте PDF и просмотрите его от первой до последней страницы.

### Постраничный график в PDF

PDF-экспорт и системная печать отчёта используют один постраничный движок.

- первая страница оформляется отдельно: заголовок и реквизиты не смешиваются с содержанием отчёта;
- вертикальный масштаб выбирается автоматически из стандартного ряда и указывается на каждом листе;
- короткая скважина печатается на одном листе без искусственного растягивания по высоте;
- длинная скважина делится на непрерывные последовательные диапазоны глубины;
- на каждом графическом листе повторяются левая и правая шкалы глубины, внешние границы, заголовки дорожек, легенда и диапазон листа;
- кривые сохраняются в векторном виде и обрезаются только по внутренним границам дорожек;
- таблицы переносятся только между строками, а шапка таблицы повторяется на странице продолжения;
- номер страницы, заголовок, легенда и примечание должны находиться внутри печатной области.

### Печать на физическом принтере Windows

1. Нажмите печать отчёта и выберите **книжную** или **альбомную** ориентацию.
2. Выберите порядок: **с первой страницы к последней** или **с последней к первой**. По умолчанию используется прямой порядок.
3. В системном окне Windows выберите принтер Epson, диапазон страниц, число копий и свойства драйвера.
4. При выборе диапазона **1–2** приложение отправляет на принтер только страницы 1 и 2 в выбранном порядке.
5. Во время подготовки страниц отображается окно хода печати. Кнопка **Остановить** прекращает передачу ещё не отправленных страниц.
6. Страницы, уже помещённые в очередь Windows или буфер принтера, могут потребовать отдельной отмены в системной очереди печати.
7. После запуска проверьте сообщение приложения о количестве страниц, переданных в очередь.

Перспективные интервалы не заменяют заключение геолога.

## 5. Справка и диагностика

Откройте **Справка → Документация и инструкции** для встроенного руководства.

При ошибке:

1. запишите последовательность действий и время;
2. сохраните исходный файл и неудачный результат;
3. откройте папку журналов или создайте диагностический пакет;
4. не повторяйте массовый экспорт до анализа причины;
5. передайте разработчику журнал, пакет, пример входного файла и снимок проблемной страницы.
