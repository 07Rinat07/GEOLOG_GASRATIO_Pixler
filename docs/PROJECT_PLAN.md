## Критерий приёмки

Окно не выходит за рабочую область активного монитора, правая команда редактирования остаётся
доступной, а менее приоритетные команды переходят в **«⋯»**. Сверхтонкий значок остаётся видимым,
выбираемым и редактируемым без изменения сохранённой геометрии. Для одного
`ResolvedReportDefinition` CSV/XLSX используют точные строки активной числовой DEPTH/TIME-оси.
