# План проекта

## Новое направление: импорт GeoScape II GS2

Цель — открыть `.gs2` напрямую, восстановить исходные TIME/DEPTH и измерительные каналы и
передать их в существующий `Dataset` без изменения исходного файла.

- [x] проверка единственного `GS2.mdb` и наличия `GS2#*.db`;
- [x] защита от path traversal, дубликатов, шифрования, zip bomb и превышения лимитов;
- [x] временная распаковка с автоматическим удалением;
- [x] выбор GS2 в универсальном импорте, отдельная команда и drag-and-drop;
- [x] RU/KK/EN диагностика и тесты синтетических контейнеров.

### Этап 5 — приёмка

- [ ] проверить файл СГ-8 и минимум два GS2 из других версий GeoScape;
- [ ] сверить выбранные каналы и диапазоны с экспортом GeoScape Exporter в LAS/Excel;

Текущий пользовательский результат: контейнер можно открыть, выбрать внутреннюю таблицу и
импортировать её в обычный `Dataset`. Автоматическое объединение таблиц и расшифровка назначений
каналов из Access остаются следующими этапами. Подробный контракт: [GS2_IMPORT.md](GS2_IMPORT.md).

## Критерий приёмки

На внешнем мониторе и ноутбуке правая команда редактирования полностью видна. При нехватке места
сначала скрываются подписи, затем второстепенные команды появляются в **«⋯»**. Значок можно
растянуть по одной или двум осям, сохранить через **Ctrl+S** и получить те же размеры после
повторного открытия, в preview, PDF и печати.
