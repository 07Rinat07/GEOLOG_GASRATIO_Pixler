# GEOLOG GASRATIO@Pixler — пользовательская документация

Руководства доступны на трёх языках:

- [Русский](USER_GUIDE_RU.md)
- [Қазақша](USER_GUIDE_KK.md)
- [English](USER_GUIDE_EN.md)

Та же информация доступна внутри приложения через меню **Справка → Документация и инструкции**.

## Структура интерфейса

- постоянные рабочие вкладки: кривые, таблица LAS и планшет;
- **Инструменты**: файлы, PDF, изображения и калькуляторы;
- **Печать**: центр печати и отчёты по интерпретации;
- **Справка**: документация, инструкции и диагностические команды.
