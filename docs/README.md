# GEOLOG GASRATIO@Pixler — пользовательская документация

Руководства доступны на трёх языках:

- [Русский](USER_GUIDE_RU.md)
- [Қазақша](USER_GUIDE_KK.md)
- [English](USER_GUIDE_EN.md)

Та же информация доступна внутри приложения через меню **Справка → Документация и инструкции**.

## Структура интерфейса

- постоянные рабочие вкладки: кривые, таблица LAS и планшет;
- **Инструменты**: файлы, PDF, изображения и калькуляторы;
- **Печать**: центр печати и отчёты по интерпретации;
- **Справка**: документация, инструкции и диагностические команды.

## ОПУС и интерпретация бурового газа

- Порядок расчёта и чтение автоматических подписей:
  [RU](ru/MUD_GAS_INTERPRETATION.md) ·
  [KK](kk/MUD_GAS_INTERPRETATION.md) ·
  [EN](en/MUD_GAS_INTERPRETATION.md).
- Формулы, единицы, границы применимости и библиографическая проверка:
  [паспорт формул](MUD_GAS_FORMULAS.md).
- Принятые решения и план реализации отдельного практического профиля по книге
  `Газомер.xls`: [инструкция «ОПУС Газомер»](OPUS_GASOMER_IMPLEMENTATION.md).
- Каждый PDF/DOCX/XLSX-отчёт ОПУС содержит паспорт методики: формулы, фактически
  использованные кривые, правило автоматической интерпретации, источники и степень
  их подтверждения. ОПУС указан как скрининговый профиль, а не как ГОСТ/ISO-стандарт
  окончательного определения пластового флюида.
