# Локализация RU / KK / EN

## Обязательная политика

GEOLOG GASRATIO@Pixler поддерживает русский, казахский и английский языки. Выбор предлагается
при первом запуске и сохраняется в `QSettings`; изменить его можно через меню
«Язык / Language / Тіл». После выбора новый язык применяется сразу к меню, вкладкам,
панелям, таблице LAS, браузеру кривых, инспектору и планшету. Перезапуск не требуется;
выбор одновременно сохраняется в `QSettings` для следующего запуска.

Каждая новая пользовательская строка должна:

1. иметь стабильный смысловой ключ;
2. одновременно добавляться в `ru.json`, `kk.json` и `en.json`;
3. использовать единый отраслевой термин из глоссария;
4. применяться также в отчётах и печатных формах;
5. сопровождаться тестом равенства ключей трёх каталогов.

Мнемоники LAS (`DEPT`, `C1`, `ROP`, `WOB`), единицы, формулы, имена файлов и исходные данные
не переводятся. Переводится их описание и окружающий интерфейс.

## Утверждённый контракт многоязычного ведения скважины

Решение от **5 сентября 2026 года**, задачи WELL-03…06 в [PROJECT_PLAN.md](PROJECT_PLAN.md).
Это целевая модель: вкладки языков, состояния готовности и пакетный выпуск ещё предстоит
реализовать. Отдельные `*_i18n` уже сохраняются; отсутствие новой функции нельзя скрывать
формулировкой «всё автоматически переведено».

Язык приложения применяется к интерфейсу, системным подписям форм/шапок, названиям литотипов,
легендам и представлению данных. Он задаёт начальную вкладку редактора и язык выдачи по
умолчанию. Проект содержит общие данные и три версии текста одной записи, а не три Dataset.
Числа, границы интервала, коды, ID и ссылки на изображения общие; изменение текста одного языка
не должно менять остальные. Для собственного имени можно сохранить утверждённое написание
без требования искусственного перевода.

Целевой редактор показывает Русский / Қазақша / English и состояние каждого поля:

| Состояние | Значение |
|---|---|
| Не заполнено | Нет собственной версии требуемого текста на выбранном языке |
| Черновик | Текст введён, вставлен из шаблона или подготовлен переводом, но ещё не проверен для этой записи |
| Проверено | Пользователь подтвердил версию относительно текущего оригинала и её зависимостей |
| Требует обновления | После подготовки/проверки изменился оригинал либо использованные параметры; прежний текст сохранён |

Хранятся исходный язык, текст/ревизия оригинала и связь каждого перевода с версией, по которой
он подготовлен. Правка источника делает устаревшими только зависимые переводы этой записи;
изменение английской формулировки не стирает русский оригинал и казахскую версию. Добавление
новой глубины создаёт новые задачи заполнения, не сбрасывая проверенные старые описания.
Общие счётчики `Well.language_revisions` недостаточны для такого контроля.

Выбор нескольких готовых описаний должен добавлять упорядоченные многоязычные блоки за одно
действие. Блок сохраняет ID и версию шаблона, параметры и снимки текстов RU/KK/EN; пользовательские
дополнения привязаны к своему языку. Обновление каталога не переписывает ранее сохранённые
описания. Применение обновлённого шаблона явно показывает изменяемые блоки и сохраняет ручные
дополнения. Согласованные три текста могут появиться автоматически из проверенного словаря;
это не машинный перевод произвольной геологической записи.

Унаследованный текст без достоверно заданного языка сохраняется как оригинал с неопределённым
языком до выбора пользователя; угадывание языка не должно приписывать ему статус перевода.
Fallback доступен для рабочего чтения с видимой отметкой происхождения, но не записывается
в соседнюю вкладку при её открытии или сохранении неизменённой формы. Смена вкладки удерживает
черновики, отмена диалога не меняет проект.

Готовность проверяется для выбранного диапазона, формы и языков выпуска. Итоговый документ
требует актуальных проверенных версий обязательных текстов; список проблем ведёт к конкретным
интервалам и полям. Необязательные пустые поля и корректные непереводимые имена не являются
ошибкой. Для рабочего черновика допускается явно отмеченный исходный текст; русский fallback
не должен незаметно попадать в документ, обозначенный как готовый казахский/английский.
Существующий runtime fallback пока сохраняется до реализации и миграции WELL-04/06.

Машинный перевод — отдельное будущее расширение с сохранением оригинала и проверкой геологом;
для первого цикла не требуются сетевые сервисы и новые зависимости. Внутренние коды состояний,
коды языков `ru`/`kk`/`en` и версии не локализуются; видимые названия состояний локализуются.

## Проверенный базовый глоссарий

| Русский | Қазақша | English |
|---|---|---|
| Скважина | Ұңғыма | Well |
| Глубина | Тереңдік | Depth |
| Месторождение | Кен орны | Field |
| Оператор | Оператор | Operator |
| Бурение | Бұрғылау | Drilling |
| Буровой раствор | Бұрғылау ерітіндісі | Drilling fluid / mud |
| Пласт | Қабат | Formation / reservoir layer |
| Пластовое давление | Қабаттық қысым | Formation pressure |
| Горная порода | Тау жынысы | Rock |
| Долото | Қашау | Drill bit |
| Ствол скважины | Ұңғыма оқпаны | Wellbore |
| Забой скважины | Ұңғыма кенжары | Bottomhole |
| Каротаж | Каротаж | Well logging |
| Кривая | Қисық | Curve |
| Отчёт | Есеп | Report |
| Печатная форма | Баспа нысаны | Print form |

Контекст важен: английское `formation` может означать геологическую формацию или пласт,
а `mud` допустим как краткая промысловая форма `drilling fluid`. Мнемоники и утверждённые
международные сокращения не локализуются.

## Документация

Исходные инженерные документы пока ведутся на русском. Для пользовательских руководств
создаются синхронные версии `docs/ru`, `docs/kk`, `docs/en`. Изменение инструкции считается
завершённым только после обновления трёх версий либо явной отметки `translation pending` в
проверке документации. Формулы, код и ссылки на стандарты должны совпадать между версиями.

## Текущее покрытие

- оболочка: меню, вкладки, панели, выбор и сохранение языка;
- универсальный импорт: общая точка входа;
- CSV/TXT и Excel: заголовки, mapping, preview, проверки и кнопки;
- LAS Table Editor: подсказки, диапазонные команды, диалоги и проверки selection;
- LAS Export Plan: версия, WRAP, NULL, точность, подтверждения и статус экспорта;
- Formula Profiles: паспорт, источник, mapping и описания DEXP на RU/KK/EN;
- Interval Statistics: меню, интервал, показатели и проверки на RU/KK/EN;
- Depth Annotations: редактор, действия, проверки и дерево проекта на RU/KK/EN;
- Lithology Intervals: редактор, действия, проверки и дерево проекта на RU/KK/EN;
- Interpretation Intervals: несколько интерпретаций скважины, CRUD, экспорт и дерево проекта на RU/KK/EN;
- Description Templates: редактор, действия, проверки и дерево проекта на RU/KK/EN;
- Lithology Legend: заголовки, пустое состояние и названия RU/EN на RU/KK/EN;
- Lithotype Catalog: таблица, форма, действия и тип источника на RU/KK/EN;
- Track Inspector: сводка, шкала, диапазон и свойства кривой на RU/KK/EN;
- Data Inspector: все вкладки, индексы, кривые, диагностика и LAS-заголовок на RU/KK/EN;
- Tablet workflow: создание и управление треками, шкалами и диапазонами на RU/KK/EN;
- Depth normalization: направления, подтверждение и безопасное создание копии на RU/KK/EN;
- Basic Gas Ratio: команда, результат, ошибки и журнал на RU/KK/EN;
- Normalized Gas: паспорт профиля и описание C1_NORM на RU/KK/EN;
- DEXP/NCT: команда, калибровочный диалог и диагностические предупреждения на RU/KK/EN;
- печать: локализованные встроенные формы и шапки, выбор языка отчёта; весь сценарий
  готовности и пакетной выдачи одной ревизии развивается по WELL-05/06.

LAS import review, редакторы метаданных, геологические диалоги и специализированные сообщения пока
мигрируют по плану. Отсутствие перевода не должно скрываться: статус фиксируется в
[едином плане](PROJECT_PLAN.md).

Каталог литотипов хранит названия RU/KK/EN. Для старых или неполных записей возможен fallback
на сохранённое название; `lithotype_id` остаётся неизменным. Авторские описания интервалов
имеют отдельные языковые поля и пока не переводятся автоматически. Текущий список «язык
шаблона» меняет язык вставляемой фразы, а язык сохранения описания определяется языком
приложения; он не заменяет целевые языковые вкладки WELL-03.
