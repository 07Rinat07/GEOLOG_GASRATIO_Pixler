# GEOLOG GASRATIO@Pixler 0.7.88 — корректное распознавание TIME/DEPTH в GeoScape2 GS2

## Исправлено

- Unix timestamp больше не распознаётся одновременно как время и глубина.
- Канал вида `1.78459e+09` определяется как абсолютное время, а не как метры.
- Один исходный столбец запрещено назначать одновременно каналом TIME и DEPTH.
- В окне GeoScape/Paradox импортёр автоматически выбирает временной режим, если таблица является временной.
- Ненадёжный кандидат глубины с уверенностью ниже 65% больше не выбирается автоматически.
- Короткие монотонные технологические каналы (ROP, torque, pressure и т. п.) больше не принимаются за глубину только из-за стабильного шага.

## Поведение после исправления

В чисто временной таблице доступны оси TIME/DATETIME. Ось DEPTH появляется только при наличии отдельного подтверждённого канала измеренной глубины. Для уже импортированного ошибочного набора требуется повторный импорт в версии 0.7.88.
