# Универсальный импорт

Первый слой аудита `DATA-PETRO-01` доступен как read-only модель
`geoworkbench.data.format_capabilities.import_format_capabilities`. Она различает
`verified`, `limited`, `unverified` и `unavailable` для metadata preview,
чтения отсчётов, проектного редактирования, записи исходного файла и экспорта
производной копии. `LasImportReport.capabilities` получает версию из фактического
заголовка VERS, а не имени файла. Точное подтверждение текущего LAS reader относится
к 1.2/2.0; другие версии и диалекты не имеют проверенного lossless round-trip.
Существующий импорт может попытаться прочитать такой файл, но предупреждает
об ограниченной совместимости. Источник не перезаписывается; новый LAS writer
поддерживает только 1.2/2.0 через анализ потерь. CSV/Excel требуют выбора индекса,
не обеспечивают побайтного восстановления исходной разметки; XLS при необходимости
использует внешний конвертер LibreOffice. Это backend audit, не новый UI-экран
и не обещание поддержки LAS 3.x, DLIS или LIS79.


Команда «Файл → Импортировать данные...» (`Ctrl+I`) является общей точкой входа для всех
реализованных локальных форматов. На первом шаге пользователь выбирает источник:

- LAS 1.2/2.0 — политика strict/compatible/manual и выбор одного или нескольких файлов;
- CSV/TXT — кодировка, разделитель, индекс, DATE+TIME и timezone;
- Excel XLS/XLSX/XLSM — лист, строка заголовка, индекс, DATE+TIME и timezone;
- GeoScape/Paradox — выбор dataset и безопасная регистрация извлечённых каналов.
- GeoScape II GS2 — проверка контейнера, выбор внутренней Paradox-таблицы либо объединённой
  многочастной TIME-серии, read-only Access-метаданные `WELLS`/`FORMULAS`, Sensors fallback и
  импорт через общее сопоставление каналов; детали — в [плане GS2](GS2_IMPORT.md).

После форматного диалога открывается единый Import Review. Пользователь проверяет активный
индекс, NULL и QC, может исключить канал и исправить canonical mapping, quantity class или UOM.
Блокирующие ошибки не позволяют подтвердить импорт, а предупреждения остаются видимыми.
Старые команды «Импортировать LAS/CSV/Excel» сохранены для быстрых рабочих сценариев.

Все завершённые адаптеры данных создают общую доменную модель `Dataset`, не изменяют оригинал и
передают в проект только валидированную копию после одной атомарной команды подтверждения.
GS2 передаёт выбранную внутреннюю таблицу в тот же атомарный поток. Отмена Import Review не
создаёт скважину или dataset и не меняет `dirty`. Подробнее: [Import Review](IMPORT_REVIEW.md).
