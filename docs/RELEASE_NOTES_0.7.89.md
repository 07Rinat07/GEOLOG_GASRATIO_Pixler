# GEOLOG GASRATIO@Pixler 0.7.89 — исправление применения форм после импорта GS2

## Причина

Форма хранит `vertical_index_id`. После открытия другого GeoScape2 dataset этот
идентификатор мог относиться к индексу предыдущего набора. Поиск через
`dataset.indexes.get(...)` возвращал `None`, после чего код обращался к
`requested.role`. Это вызывало ошибку:

```text
'NoneType' object has no attribute 'role'
```

Та же ошибка возникала при попытке транзакционного отката, поэтому приложение
сообщало, что предыдущую форму не удалось полностью восстановить.

## Исправлено

- Добавлено безопасное разрешение вертикальной оси с проверкой существования ID.
- Для устаревшего ID используется активная ось текущего dataset, затем первый
  доступный индекс DEPTH/TIME.
- Кандидат формы сначала привязывается к `TabletView`, и только после этого
  выполняется согласование GeoScape2 TIME/DATETIME.
- Откат формы использует тот же безопасный путь.
- Старые относительные оси TIME для абсолютных временных данных мигрируют в
  DATETIME.
- Явно выбранная ось глубины сохраняется.
- В журнал добавлено событие `tablet.vertical_axis.reconciled`.

## Совместимость

Форматы проекта, формы и планшета не менялись. Проекты 0.7.88 открываются без
миграции данных.
