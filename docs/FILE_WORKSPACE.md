# Рабочее пространство «Файлы» / «Файлдар» / Files workspace

Отдельная вкладка предназначена для документов и инженерных операций, которые не требуют
открытого LAS-проекта. Она доступна через меню **Файл → Файлы / Files** и сочетание
`Ctrl+Alt+F`.

## Русский

### Документы

Вкладка открывает PDF, JPEG, PNG, TIFF и BMP. Документ отображается в прокручиваемой области с
масштабом от 10 до 800 процентов. Для PDF доступны переход по страницам, добавление текста,
выделение, примечание, удаление аннотаций и необратимое скрытие содержимого выделенной области.
До сохранения изменения можно отменять и повторять. Для изображений доступны изменение размера,
обрезка по выделенной мышью области, яркость, контраст, насыщенность, резкость, оттенки серого и
автоконтраст. Команды «Сохранить» и «Сохранить как» записывают результат отдельно от проекта.

### PDF-инструменты

Объединение создаёт один PDF в порядке выбора исходных файлов. Разделение создаёт отдельный PDF
для каждой страницы и не перезаписывает существующие файлы. Экспорт в DOCX переносит доступный
текст PDF в стандартный OOXML-документ. OCR не выполняется, поэтому скан без текстового слоя
будет экспортирован с уведомлением об отсутствии распознаваемого текста.

### Логотипы

Конструктор создаёт PNG, JPEG, BMP или TIFF с произвольным текстом, размером, цветами, рамкой и
прозрачным фоном. Предпросмотр использует тот же растровый результат, который сохраняется в файл.
Системный шрифт выбирается автоматически; внешние файлы шрифтов в проект не встраиваются.

### Архивы

ZIP и TAR, TAR.GZ, TAR.BZ2, TAR.XZ создаются и распаковываются встроенными средствами Python.
7Z и RAR включаются только при обнаружении `py7zr`, `rarfile`, 7-Zip, WinRAR, RAR или UnRAR.
Интерфейс показывает фактические возможности текущего компьютера. Перед распаковкой проверяются
абсолютные пути, `..`, Windows drive paths, ссылки, количество элементов и суммарный размер.
Файлы извлекаются во временный каталог и только после проверки перемещаются в выбранную папку.

### Инженерные расчёты

Калькулятор поддерживает арифметику, безопасный набор математических функций, `pi`, `e`, а также
обычные, смешанные и Unicode-дроби: `1/2`, `2 1/2`, `2-1/2`, `½`. Произвольный Python-код не
выполняется. Конвертер охватывает длину, давление, температуру, площадь, объём, массу, силу,
крутящий момент, плотность, расход, скорость, энергию и угол. Блок вертикальных отметок строит
цепочку `datum → GL → wellhead/DF → RT → KB/RKB` в метрах и допускает отрицательные смещения.

## Қазақша

«Файлдар» қойындысы LAS жобасын ашпай-ақ PDF пен кескіндерді қарауға және өңдеуге мүмкіндік
береді. PDF үшін мәтін, белгілеу, ескертпе, аннотацияларды жою, аймақты жабу, беттерді біріктіру
және бөлу, сондай-ақ мәтінді DOCX форматына шығару бар. JPEG, PNG, TIFF және BMP үшін өлшем,
қиып алу және түс түзету қолданылады. Логотип құрастырғышы мәтін, өлшем, түс, жиек пен мөлдір
фонды сақтайды. ZIP және TAR пішімдері әрқашан қолжетімді; 7Z/RAR тиісті backend табылғанда ғана
қосылады. Архив жолдары мен көлемдері шығарудан бұрын тексеріледі. Инженерлік бөлім қауіпсіз
калькуляторды, бөлшек дюймдерді, өлшем бірліктерін және datum, GL, wellhead, DF, RT, KB/RKB
белгілерін есептеуді қамтиды.

## English

The Files tab works independently of an open LAS project. It displays and edits PDF, JPEG, PNG,
TIFF and BMP documents, including PDF text, highlights, notes, annotation deletion and area
redaction, plus image resize, crop and colour correction. Separate PDF tools merge documents,
split pages and export selectable text to a dependency-free DOCX file; OCR is intentionally not
performed. The logo builder saves text-based raster logos with configurable dimensions, colours,
borders and transparency. ZIP and TAR-family archives are always available, while 7Z and RAR are
enabled only when a compatible backend is detected. Extraction rejects traversal paths, links and
resource-limit violations before moving staged files to the destination. Engineering tools provide
a restricted-expression calculator, mixed and Unicode fractions, unit conversion and a vertical
reference chain for datum, GL, wellhead, DF, RT and KB/RKB elevations.

## Проверка и ограничения

Автоматические тесты проверяют смешанные дроби, запрет выполнения Python-кода, преобразование
дюймов, цепочку высот, ZIP round-trip и path traversal, редактирование изображения, создание
логотипа, объединение/разделение PDF и структуру DOCX. Windows Release Gate дополнительно
проверяет запуск главного окна, HiDPI-геометрию, PDF-приёмку, зависимости и исходный код.

Парольные PDF не изменяются. Экспорт DOCX сохраняет текст, но не пытается полностью повторить
графическое расположение PDF. RAR-создание требует WinRAR/RAR, поскольку свободного встроенного
кодировщика RAR в приложение не включено.
