## Статус проверки

Четыре опубликованных показателя ОПУС перенесены независимо в
`geoworkbench.calculations.gas_ratio` и покрыты контрольным примером. Пятый
показатель, нормализация по TotalGas и строгая мода пяти голосов не имеют
достаточной проверяемой опоры в найденных источниках и не подключены к runtime.

Подробная формула, источники и границы применения описаны в
[`docs/MUD_GAS_FORMULAS.md`](../../docs/MUD_GAS_FORMULAS.md).
